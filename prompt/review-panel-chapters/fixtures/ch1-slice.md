# Ch1 章切片 fixture

CHAPTER: 1

## 1. 概述

### 1.0 本章导读

#### 问题入口

引导器把控制权交给内核时，内核必须先判断哪些数据必须带走、哪些只是临时视图，以及怎样确认“交接已经成功”。判断错了，内核会把固件占用的内存当成可用内存，或者读到一个自己无法访问的地址。

#### 前置概念

只需要知道引导器会把控制权交给内核；本章不要求了解具体载荷类型或协议。

### 1.1 三类数据

交接要带走三类数据：

- 可用内存的图：记录哪些物理内存区间可用、哪些被固件占用。
- 内核镜像的位置：内核自己落在哪里、有多大。
- 交接结构：引导器按约定布局写给内核的一小块记录。

三者都必须按值交付（复制内容，不传递发送侧地址）。内核先要知道内存、自己和描述三者的位置，才能开始使用。

### 1.2 四条通用不变量

这四条对应交接的四种典型失败：地址跨不过去、来源说不清、两个所有者释放同一块内存、没校验就先使用。

1. 值可跨边界：不依赖发送侧地址。
2. 来源可追溯：每个字节能说出谁给的。
3. 所有权唯一：一份数据只有一个所有者。
4. 校验先于消费：接收方使用前完成校验。

### 1.3 与 C 实现的对应

C 侧在同一地址空间内的做法见第二章；这里只需记住：地址不能跨镜像，内容可以复制。

### 1.4 范围与接缝

本篇只讲数据准备与发送；镜像映射与换栈归另一篇。具体载荷类型与协议见第三章。

#### 失败对照

如果只把地址交给接收方，接收方在自己的地址空间里可能读不到那块内存；所以必须复制内容，而不是复制地址。

#### 最小示例

1. 取一份内存布局描述。
2. 标出可用区间与被固件占用的区间。
3. 对每个可用字节问一句“谁声明它可用”，答不出就拒绝。

#### 小结

- 交接要带走内存图、镜像位置与交接结构三类数据。
- 四条通用不变量分别防地址、来源、所有权与校验四类失败。
- 地址不能跨镜像，内容可以复制。

#### 术语

- **可用内存图**：记录哪些物理区间可分配、哪些被占用的数据。
- **交接结构**：引导器写给内核的一小块定长记录。
- **按值交付**：复制内容，不传递发送侧地址。
- **消费**：接收方第一次使用这份数据。
