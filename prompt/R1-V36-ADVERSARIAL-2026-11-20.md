## 二、关键设计决定：停止给散文极性打补丁（F4/F10 的正确修法）

三轮对抗（b5 → 本轮的 F4 → F10）都在同一条正则上补词表，每次修完又出新反例：
`P0 = 0` / `无 P0` / `P0（0）` / `P0(0)` / `P0 无新增，P1 遗留 1 项` / `P0/P1：0 / 2` /
`本次无 P0/P1 遗留` / `P 0 遗留 1 项`。**这是本项目 18 轮文本门循环的同一个病根**：
散文极性是开放集合，正则补不完。

**V3.6 的处置：改契约形态，不改正则。**
- V3.6+ 回执**必须**含 `- 遗留 P0: <n> / P1: <n>` 一行（`review-panel.md` §4.7 已写入）；
- 门只读这两个数；**缺失 = fail-closed**（无可判定读数即不合规）；
- V3.5 及更早回执保留旧启发式，只求不误伤（六篇实测 0 误伤）。
- 这同时解决了 b5 的原始问题（六篇回执「全都不敢写 P0 字样」）：现在写计数是**义务**，
  不是风险。
