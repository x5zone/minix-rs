# style-fix

## 目标
提升教学性，for 读者。修文风、去开发文档味、章节重组、细节深度归位。

## scope（用户未指定时确认）
`section`（默认）/ `chapter` / `doc`。

## 执行
按 `prompt/review-rules/review-cmds.md` §三：三步审计（章节组织 → 逐节开发文档味 → 细节深度）→ 修复。
文风硬约束见 §六 style-bible：技术博客文风、禁黑话/缩写/文言文/压缩简写、禁"旧版/最初/后来"叙事（模式 64）、Ch1 主语是 CPU/OS/机制而非函数名。

## 强制门
锚点纪律门（模式 83）+ 文风门。

## 不做
不改代码语义；不做 C 覆盖度判断（发现 → 记录交 full-review）。

## 产物
三类审计结果 + 修复稿 + 自检（裸概念复述测试）。
