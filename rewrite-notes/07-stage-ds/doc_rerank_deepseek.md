## 1. C 真序

### 1.1 阶段类型判定

判定为**服务事件循环型**（与 05/06 同型）。理由：DS 常驻，`main()`（`main.c:28`）进入 `while (TRUE)`（`main.c:42`）永不退出；启动段只有"取机器/清表/映射 boot 服务"三步；全部业务在"收消息—分发—处理—回复"循环内。DS 是**全系统最小的用户态服务**（811 行 C），但它是 boot image 中第一个用户服务（`kernel/table.c:52`），承担全系统的 label→endpoint 注册中心职责。

### 1.2 真序表

**启动段**（从 boot image 登记到进入主循环）：

| 步 | 动作 | C 锚点 | 说明 |
|----|------|--------|------|

| S02 | 内核加载映像；非 VM 进程挂 `RTS_VMINHIBIT` | `kernel/main.c:196`（VM 立即可调度）、`:265-267`（其余抑制） | 执行序与登记序是两回事（06 篇核心区分） |

| S04 | SEF 本地启动：注册 fresh/restart/LLVM 状态转移 | `main.c:93-104` | `sef_setcb_init_fresh`、`SEF_CB_INIT_RESTART_STATEFUL`、`sef_llvm_ds_st_init`（`main.c:100`） |

### 4.0 结构决策与理由

**结论：保留 00-12 + 99 的既有 14 篇编号与顺序，不新增、不合并、不拆分；对 00/99 做整体重写，对其余 12 篇做"原地重建 + 边界收束 + 事实纠错"。**
