## 1. C 真序

### 1.1 阶段类型判定

判定为**服务事件循环型**。IPC server 是 SysV 信号量与共享内存的**用户态对象管理服务**（≠ 内核 send/receive/notify 原语，后者归 01-stage-kernel/12）。不在 boot_image，由 `ipc.conf` 授权、RS 拉起；主循环四步；两条主线：启动顺序（SEF→kern.ipc MIB 子树→主循环）与 SysV 调用旅程（SEMGET/SEMOP/SHMGET/SHMAT 等七调用）。

### 1.2 真序表

**启动段**：

| 步 | 动作 | C 锚点 | 说明 |
|----|------|--------|------|
| S01 | RS 按 `ipc.conf` 权限拉起（system UMAP/VIRCOPY；vm 五项访存动词） | `ipc.conf`（18 行） | 阶段入口 |
| S02 | `main` → `sef_local_startup` 注册 fresh/restart/signal | `main.c:123-136,216-284` | SEF |
| S03 | `sef_cb_init_fresh`：清两表 + 注册 kern.ipc MIB 子树（本地或远端静默） | `main.c:80-99` | boot 锚点 |
| S04 | 进入主循环 | `main.c:227` | — |

**循环段**：

| 步 | 动作 | C 锚点 | 说明 |
|----|------|--------|------|
| L01 | 收消息（`sef_receive`；失败累计上限） | `main.c:229` | 收 |
| L02 | 三层专用分流：kern.ipc 查询 / PROC_EVENT / 普通调用 | `main.c:234-252` | 分流 |
| L03 | `call_vec` 七表项分发（SHMGET/SHMAT/SHMDT/SHMCTL/SEMGET/SEMCTL/SEMOP） | `main.c:12-20,255-270` | 分发 |
| L04 | 回复门：`SUSPEND` 不回（semop 挂起）、`EDONTREPLY` 不回（sem.c:887 退出） | `main.c:273-280`；`com.h:1151` | 回复 |
| L05 | 回到 L01 | `main.c:227` | — |

**SysV 调用旅程**（次主线）：

| 步 | 动作 | C 锚点 |
|----|------|--------|
| J01 | `semget`：键/id 查找 → 创建两分支（15 位序号绕回）→ 权限 | `sem.c:53-87,93-156` |
| J02 | `semctl`：13 命令（GETVAL..SETALL、SEM_STAT/SEM_INFO、IPC_RMID/SET/STAT） | `sem.c:469-648` |
| J03 | `semop`：入口七步 → 试执行乐观回滚 → 连锁重试 → 挂起等待（iproc） | `sem.c:654-779,294-423,163-244` |
| J04 | `shmget`：1024 槽 → 创建两分支 → `vm_getphys` 快照 | `shm.c:15-127` |
| J05 | `shmat`：重映射 → 惰性引用计数刷新（nattch）→ 1 字节 rc | `shm.c:130-206` |
| J06 | `shmdt`/`shmctl`：按物理认亲 → 六命令（删名/销毁分离、SHM_DEST 延迟） | `shm.c:209-242,261-371` |
| J07 | 进程事件：订阅掩码边沿触发 → PROC_EVENT 分诊 → 取消等待（EIDRM/EINTR） | `main.c:144-214`；`sem.c:866-888` |
| J08 | SIGTERM：双表空则摘树 exit(0)，否则警告留下 | `main.c:101-122` |

### 7.1 缺口逐项展开（§3.3 的 G-01 到 G-12）

原料行号都是本轮实测（命令与输出见 §0.3 与 §8.2）。归篇一列用的是 §8.1 的新小节名。

**G-01　02 篇称 EDONTREPLY 本服务不用**
- 主题：02 篇旧文把 EDONTREPLY 列为本服务不使用的伪状态，与 C 源码事实相反。
- 为什么重要：EDONTREPLY 是回复门的第三个出口，写错会让读者以为挂起的 semop 在进程退出时必然收到 EINTR，从而误判 06 篇的三路叫醒与 09 篇的取消路径。
- 原料：`minix3/minix/servers/ipc/sem.c:887`（`complete_semop(ip, has_exited ? EDONTREPLY : EINTR);`）、同文件 `sem.c:223`（complete_semop 定义）、常量 `minix3/sys/sys/errno.h:199`、Rust 侧 `os/servers/ipc-server/src/sem/waiter.rs:178`（cancel 带 exited 参数）。
- 归篇：02 §4 回复语义改正表述；06 §5 完成与取消承接用法；99 §2 错误码保留常量行号。
