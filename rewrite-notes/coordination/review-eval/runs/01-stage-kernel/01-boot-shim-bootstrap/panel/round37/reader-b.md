## 3. SUGGESTION

1. **§2.2 末尾“标题里的三个配套教学点”**（第 179 行）：§2.2 的标题是“`head.S` 第一跳：`load_stack_start → pre_init`”，没有“三个配套教学点”这句话。建议改成“上面这三段”，或把“三个配套教学点”补回标题。这是悬空的自我指涉，读者会去标题里找不存在的短语。

2. **§1.1 第三行“前三样必须按值深拷”**（第 16 行）：表只有三行，第三行本身就是“交接结构”，说“前三样”会把容器再算一遍。建议改成“前两样装进第三样，整体按值深拷”，或“三份数据整体按值深拷”。

3. **§2.6 与 §2.1/§2.5 重复，且最后一段跳到 Rust**（第 754–764 行）：本节开头说“三层检查”，随后把 §2.1 的 `load_mods` 次序与 §2.5 的 `overlaps`/`-1` 又讲一遍，最后一段转到 `FileLoader`/`place_modules`。建议压成一张“三层检查 → §2.1/§2.5 锚点 → 失败信号”的对照表，把 Rust 段移到 §4.3；或者把标题改成“小结与 Rust 对照”，明确它是小结而不是新的 C 分析。

4. **§4.1 与 §4.2 对同一个 UEFI 入口各讲一遍**（第 1712 行与第 1747 行）：§4.1 给“三段式”概览并引 `main.rs`，§4.2 给“九动作/十拍”的细节并引 `prepare_and_enter_kernel_image`。建议 §4.1 只留导航（入口 + 阶段表 + 指向 §4.2），把流程细节集中到 §4.2；否则读者无法判断哪一份是权威。

5. **§4.2.1 的编号过载**（第 1852 行）：同一节同时使用“动作 ID（非时序）”“时间序拍号”“§4.1 的 Step 0–4”“§4.2.2 的描述符判定五步”，并专门写了一段“另注意三套编号的共存”。建议把拍号并进动作表的行序（表按时间排，动作 ID 另列），去掉一套编号；否则读者要在四个编号系统之间来回换算。

6. **§2.4 的“2.4 结算”不是最终账**（第 510 行）：这一节明确说“框 1 要到 §2.5 的 `cut_memmap` 之后才完成”，却把 §2.4 的小结叫“结算”。建议改叫“阶段小结（尚未扣除占用）”，避免读者把“结算”当成清单已完成。

7. **§2.1 的 Multiboot 识别头解码与 §2.3 的 `rootdevname` 用户态落链是长可选支线**（第 66–138 行、第 316–349 行）：前者作者自己说“读本仓 boot2 路径可以整段跳过”，后者一路讲到 PM/RAMDS/mib。建议各加一个“可跳过”框：识别头移到附录或折叠块；`rootdevname` 只留“内核只当搬运工，完整落链见 PM/RAMDS 篇”这一句，把多分支图移到用户态文档。这样主线（三份数据）不会被两段支线切开。

8. **重复的 `---` 分隔线**（第 919–920、2364–2365、2579–2580 行）：每处都是连续两条，建议删一组。这是纯排版，不影响论证，但会让结构标记显得不可信。

9. **审计占位无法回查**（全文，例如“阶段”“设计裁决”“评审发现 A'”“冻结决策”）：正文多处用这些词当论据，但读者无法解析它们指哪一条记录。建议恢复具体编号，或统一移到脚注/附录；至少不要让“为什么删这个字段”这类关键结论只挂在一个不可解析的占位符上。

10. **§5.1/§5.4 的“不能互相另一”“不能另一”**（第 2371、2390 行）：疑为“替代”的残文；§5.5 的 `R02-阶段/阶段/阶段` 是占位串。建议修文并还原编号。

11. **§7.5 的 `mem_high_phys` 行**（第 2648 行）指向“§1.2 / §2.4 / §3.2”，但 §1.2 不讨论 `mem_high_phys`。建议改成“§2.3 / §2.4 / §3.2”，避免速查表把读者送到不变量表。

12. **§3.4.1 的“C 侧的归还机制照旧运转”与 §2.4.2 的“还引导段”重复**（第 1247 行与第 637 行）：同一件事在两章各讲一遍，且两处对 `kernel_may_alloc` 时点的描述都很长。建议一处讲、另一处只给指针。

## 4. 复核结论

主线是成立的：文档确实把“交接是数据问题”讲成了一个可复述的论证，C 侧的 `mbi`/`kinfo`/`memmap` 与 Rust 侧的 `KernelInfo`/`BootStorage`/wire 能对上，“什么、从哪来”这两个问题有明确答案。四条不变量也不是装饰，它们确实在组织第 3 章和第 5 章。

但读者目标只完成了一半：

- “三份数据是什么、从哪来”能独立复述；§1.1 的第三行是容器而不是并列载荷，措辞需要收紧。
- “谁拥有”需要从 §3.4（I3）跳到 §3.7（I4）才能拼出来；I3 的节不回答 I3 的判据。
- “在哪一步校验”有两个互相矛盾的顺序：§1.2/§3.7 的摘要链与 §4.4 的逐腿序不一致。
- 证据一章（第 5 章）被六处引用为“唯一权威”，但 5.3/5.4/5.5 没有承诺的表和关闭记录；读者无法判断真机证据到底证明了哪条不变量。

结构债集中在三个接缝：§1.1/§1.2/§1.4 的框架与引用；§3.7/§3.8/§3.4 的编号回填；第 5 章的证据权威。先修这三处，读者的“无法判断”会去掉大半。其余是措辞与可选支线的排布，放在 SUGGESTION 里。
