## 结构重建（独立版，不引用其他评审）

我把全文读成一条“布局事实 → 设计决策 → 实现证据 → 可观测判据”的链：

1. **问题定义（§1）**：一个镜像在链接期有 VMA/LMA 两套地址；装载者按 `p_paddr` 把段体放到物理内存；页表决定运行期哪些地址可访问。三件事——链接布局、装载摆放、成对跳转——必须彼此对齐（§1.2 表）。
2. **C 侧的证据链（§2）**：
   - 链接脚本用 `_kern_phys_base` / `_kern_vir_base` / `_kern_offset` 与 `AT()` 产出两套地址；带 `AT()` 的段平移量一致，低侧 `.unpaged_*` 段平移量为 0（§2.1）。

   - 归纳：符号值在高侧、段体在低侧、平移量是 `_kern_offset`（§2.5）。
3. **Rust 设计（§3，五条）**：

4. **实现（§4）**：`build.rs` 按 target 选三份生产脚本（§4.1）；`parse_ehdr` → `compute_kernel_layout` → `load_segments_into_phys_memory` 的装载链（§4.2）；三架构 asm（x86_64 `call`、aarch64 `ldr` + `br`、riscv64 `la` + `delta`）（§4.3）；四条路径在 `kmain` 合流（§4.4）；与 C 的逐机制对照（§4.5）。
