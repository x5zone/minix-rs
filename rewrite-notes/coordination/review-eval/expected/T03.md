# T03 期望判定 —— 架构泄漏

- **样本**：`traps/T03-arch-leak.rs`
- **盲区**：B-13
- **期望发现**：
  1. 共享层出现 x86 专有的 `mov cr3`、`invlpg` 与 `core::arch::asm!`；
  2. 这不是命名问题，而是硬件承载对象进入了操作系统语义层；
  3. 修复方向是移到 `arch/x86_64`，或在其后放一个架构 trait，由共享层依赖语义接口。
- **负期望**：
  - 不许把它降级成“函数名不够抽象”；
  - 不许只说“加注释说明这是 x86”；
  - 不许要求所有架构都实现同一个内联汇编。
- **判定**：说出“硬件机制泄漏 + 修复方向” = PASS；只说“应移到 arch 目录” = PARTIAL；只说命名或注释 = FAIL。
