# T05 期望判定 —— 哨兵错误

- **样本**：`traps/T05-sentinel-error.rs`
- **盲区**：B-01
- **期望发现**：
  1. `-1` 是哨兵返回值，类型没有强制调用方处理“未找到”；
  2. `i32` 同时承载“索引”和“错误”，`as i32` 还可能截断；
  3. 应改为 `Option<usize>` 或 `Result<usize, E>`。
- **负期望**：
  - 不许只加注释“返回 -1 表示未找到”；
  - 不许保留哨兵并增加一个常量；
  - 不许把 `-1` 改成 `u32::MAX` 就算修复。
- **判定**：指出哨兵并给出 `Option`/`Result` = PASS；只指出哨兵 = PARTIAL；只加注释或换一个哨兵值 = FAIL。
