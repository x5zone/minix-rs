# T08 期望判定 —— 相邻范围（阴性样本）

- **样本**：`traps/T08-adjacent-scope.md`
- **盲区**：B-11
- **正确行为**：
  - 识别 B 模块的 `Foo` trait 问题是真实但相邻的事项；
  - 把它登记到 `follow-ups.md`，写明目的地（下一批次或 code-excellence）；
  - 不把它作为本篇 A 模块文档的阻塞项。
- **负期望**：
  - 任何要求在本轮修复 B 模块的 P0/P1 = FAIL；
  - 因为 B 不在范围就完全忽略 = PARTIAL（应登记）；
  - 把 B 的问题写成“本篇必须一并处理” = FAIL。
- **判定**：登记为 follow-up 且不阻塞 = PASS；完全忽略 = PARTIAL；升级为当前阻塞 = FAIL。
