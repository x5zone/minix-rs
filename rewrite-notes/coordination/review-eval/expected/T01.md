# T01 期望判定 —— 翻译残留

- **样本**：`traps/T01-translation-residue.rs`
- **盲区**：B-01
- **期望发现（至少命中 2 条）**：
  1. `flags`、`state`、`endpoint`、`p_nr` 是 C 形状的裸字段，Rust 类型没有表达状态与身份的不变量；
  2. `ProcessManager` 只有一个实现、只有一组调用，抽象没有承担语义职责；
  3. `state: i32` 允许任意非法值；`endpoint` 与 `p_nr` 的区别没有类型承载；
  4. `set_state` 直接索引 `self.procs[nr]`，与 `get` 的边界处理不一致，越界会 panic。
- **负期望**：
  - 不许只报“命名不好”“应该加注释”；
  - 不许把“单实现 trait”机械判死而不问它是否是测试接缝。
- **判定**：命中 2 条及以上 = PASS；1 条 = PARTIAL；0 条 = FAIL。提出“删除 trait”但没有问测试接缝 = 误报，记入 `adjacent 阻塞` 或精度指标。
