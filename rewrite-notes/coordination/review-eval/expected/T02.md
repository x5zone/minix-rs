# T02 期望判定 —— 死抽象

- **样本**：`traps/T02-dead-abstraction.rs`
- **盲区**：B-02
- **期望发现**：
  1. `ClockSource` 只有一个实现 `Hpet`，只有一个调用点 `now_ms`；
  2. 抽象没有表达两种可替换语义；如果它不是测试接缝或未来扩展点，应当内联；
  3. 必须给出条件判断：如果保留，理由是什么；如果删除，调用方如何改。
- **负期望**：
  - 不许无条件要求删除；
  - 不许只报“trait 命名太泛”；
  - 不许忽略“可能是测试接缝”这一可能性。
- **判定**：提出条件判断并明确测试接缝 = PASS；只报单实现 = PARTIAL；无条件删除或完全忽略 = FAIL。
