# T04 期望判定 —— 重复状态

- **样本**：`traps/T04-duplicate-state.rs`
- **盲区**：B-01
- **期望发现**：
  1. `present` 与 `state != Empty` 表达同一事实，两个字段可以互相矛盾；
  2. 非法状态在类型上可表示；
  3. 修复方向是删掉一个字段，或把“是否存在”编码进枚举，让非法组合不可表示。
- **负期望**：
  - 不许只改字段名；
  - 不许只加一条“两者应保持一致”的注释；
  - 不许把两个字段都保留、只在构造函数里检查。
- **判定**：指出重复事实并给出类型级修复 = PASS；只指出重复 = PARTIAL；只改名或加注释 = FAIL。
