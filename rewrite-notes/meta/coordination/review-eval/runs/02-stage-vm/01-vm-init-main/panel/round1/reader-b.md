独立重建的结构判断（只读本篇，未看源码与其他材料）：

本文的宏观弧线是「概念 → C 源码 → Rust 设计 → 实现 → 测试 → 过渡」，五章都自带「本章要回答的问题 / 最小示例 / 失败对照 / 回顾 / 术语」模板，骨架是成立的。断裂发生在三个接缝：概念章生产的两套模型（A–E 五阶段、四条前提）在后文没有被消费；C 章与 Rust 章之间的边界两次泄漏；测试章承诺的真机门内容整节缺席。以下按根因分组。
