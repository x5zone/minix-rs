通过项
- 问题入口成立：L7 用“读到的却是自己地址空间里一段无关内容——不报错，只有错的数据”立起静默失败现场，随后给出两问与 §1.1、§1.2、§1.5 的阅读路线；L11–L14 把页错误、地址映射限定为已会词。
- 学习路径可跟做：1.1 三类数据表（L22–L26）→ I1–I4 可检查问法（L36–L39）→ 1.5 四问遮答（L77–L84）→ 1.6 自检（L108）；示例逐条复现表中问法，L91 的长度与不重叠算术正确，L96 给出两个拒绝反例。
- R1 主旨讲清：L28“镜像位置由链接时的布局结果确定……不必从交接结构复制”给出来源机制与“可重建的数据不必跨边界复制”的原则，L89 在示例中重述镜像位置的来源是链接布局。

问题
- P1 交接归属自相矛盾：L79 问“谁负责一次性发布这三段区间与镜像位置？”，但按 L28 与 L89，镜像位置不进交接结构、内核从同一链接布局读出，它没有交接发布者；L90 只给交接定“引导器是这次交接的唯一所有者”、给镜像位置定“来源是链接时的布局”，没有回答它的发布者，而 L94 仍称“四问全过”。L45 又宣称“三类数据都要过 I1–I4”，但 I1 与 I3 是跨边界与发布问题，对本地重建的镜像位置并不成立。修法：把镜像位置从 I1/I3 的交接对象中划出（写明“本地重建，不适用跨边界与发布问题”），或在 I3 中把发布者归到链接/构建阶段并说明内核本地重建。
- P2 问题入口只覆盖 I1：L7“本章要回答两个问题”的坏现场是地址误读；I2/I3/I4 的来源、所有权、校验失败直到 L53 才有一句现场。建议入口补一句三类坏法（来源说不清、两方各写一半、未校验就用），让 L102 的 I1–I4 学习目标在入口有对应。
- P2 术语表覆盖不全：L18 定义、L37/L45 反复使用的“转交者”没有独立条目，只在 L124 的“来源/所有者”里带过；并列的“发送侧/接收方”却有 L117 专条。L45 的“声明者”也未在术语表标为别名。补一条“转交者”、在来源条目加“声明者（来源）”即可。
- P2 L118 把交接结构写成“不指向发送侧地址空间”，比 L47（物理指针同样不可跨边界）和 L121（“物理或虚拟”）窄；统一为“不指向发送侧内存（虚拟或物理）”。
- P2 L21“内核真正需要带走的东西”与 L28“不必从交接结构复制”有措辞摩擦；L28 已当场解释、L89 已重述，建议把 L21 改为“内核必须知道的数据，其中只有内存图与交接结构需要复制”，消除“带走等于复制”的预设。

结论：问题入口与四段学习路径成立，R1 的正文修复有效；但示例的 I3 没跟上 R1，属教学路径上的实质缺口，修完这条 P1 即可放行。
