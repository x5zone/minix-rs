## 2. 引入顺序评估

### 2.1 成立的部分

- L7 用具体坏结果开场（“不报错，只有错的数据”），不是定义开场，问题入口成立。
- 1.1 先给三类数据，再在 1.2 给不变量，符合“先对象、后判据”。

- 1.5 示例在 1.2 之后，1.6 收束在最后，骨架正确。

### 2.2 主要问题：理论到练习的弧被 1.3、1.4 打断

当前顺序是：1.0 导读 → 1.1 三类数据 → 1.2 四条不变量 → **1.3 接缝 → 1.4 范围** → 1.5 示例 → 1.6 回顾。

读者刚在 1.2 建立 I1–I4（含 I4 的四个子检查、L41 的重叠例外、L43 的时序前提、L45 的三种角色），正要练，却被两节不判定的元信息隔开。后果有三：

1. **工作记忆干扰**：1.3 引入“高半”这一虚拟地址概念，而 1.5 的示例全是物理区间，读者会怀疑示例里的低地址是否另有含义。示例不需要高半，这个插入纯属干扰。
2. **练习被推迟**：L84 要求“先遮住下一段，自己答一遍”，但读者要跨过两节才能回到四问。
3. **导读自相矛盾**：L7 的路线图写“先定三类数据（第 1.1 节），再给四条通用不变量（第 1.2 节），然后用数值示例检验（第 1.5 节）”，直接跳过 1.3、1.4。路线图等于承认这两节是旁支，却仍排在主弧中间。

### 2.3 节序依赖结论

- 1.3（接缝）与 1.4（范围）都不被 1.5、1.6 依赖，可以整体移位。
- 1.4 是“读前边界”，应在读者进入正文前给，放在 1.0 最自然。
- 1.3 是“读后出口”，应在掌握物之后给，放在示例之后、回顾之前或回顾之后都成立。

## 4. 示例与失败对照的教学功能

### 4.1 最小示例（L71-L96）

成立之处：

- 不写代码，只用区间记法，符合概念章定位。
- 四问（L77-L80）与 1.2 表格“可检查的问法”逐条对应，读者能看出这是同一套判据的应用。
- L84 “先遮住下一段，自己答一遍，再对照”是明确的检索练习设计，意图正确。
- 题面数值自洽：三段区间互不重叠、镜像落在第二段内且可裁掉、所有边界按 4 KiB 对齐；失败变体 [0x500000, 0x540000) 确实落在所有可用区间之外。
- L96 的两个失败变体（镜像落在区间外、记录里放指针）分别演练 I4 布局与 I1，并示范“第 1 问否决后不必再看后三问”的短路判断。

关键缺陷（INS-01，P1）：

**题面给定不足以回答四问中的三问。** L75 只给了区间、镜像位置、版本一致、对齐四条；没有给：

- 记录里放了什么（I1 无法判断）；
- 三段区间与镜像位置的声明者与依据（I2 无法判断）；
- 发布时序（I3 无法判断）；
- 是否做过长度/布局/版本/来源检查（I4 无法判断）。

但 L84 要求读者遮住答案自己答。读者实际只能猜。L88-L92 的答案是把这些事实直接宣布出来，而不是从题面推出。这让“检索练习”退化为“读模型答案”，示例的教学功能损失大半。

最小修复：把 L88-L92 所依赖的前提前移到 L75 的题面（谁声明、谁转交、记录何时写入、记录里有什么、版本一致），答案只做判定。具体文字见 §9 INS-01。

次要问题：

- 版本检查只被 L75 假定为真，从未演练失败（INS-10）。四个子检查中唯一没有对照的一项，恰是最抽象的一项。
- L88 的“记录里只有物理区间值与版本号”与 L26/L28 的“承载其他必要启动参数”不一致（INS-05）。

### 4.2 失败对照（L49-L53、L96）

成立之处：

- L51 把 I1 的失败链讲全：发送侧有效不等于接收侧有效 → 复制内容而非指针 → 故障推迟到首次使用 → 可能页错误也可能静默读错。这是本章最完整的因果链。
- L53 用“有记录、没出处”“两个发布者各写一半”给 I2、I3 各一句现场，密度控制得当。
- L96 的短路示范有价值：它暗示四条不是平级清单，而是有检查次序。

不足：

1. **I3 的失败描述与前提不匹配**（INS-06）：L53 说“两个发布者各写一半，接收方读到一份自洽但过时的记录”。“各写一半”产生的是拼接/不完整，不是“过时”；“过时”暗示旧版本，与“各写一半”不是同一故障。应改成“拼起来自洽、但不属于任何一次完整提交”。
2. **只有 I1 展开，I2/I3/I4 各一句**：这是 L51 明说的取舍，可接受；但既然 L53 已给 I2/I3 现场，至少应让 I3 的描述自洽，否则唯一的 I3 失败印象是错的。
3. **根因/后果作为分析动作没有先教**（INS-08）：L102 的掌握声明要求“说出根因是哪条”，L108 的自检给 I1 根因、I4 后果、I2 连带，但正文直到 1.6 才第一次做这种区分。应在示例收尾处（L94 之后）补一句，把“同一故障可踩多条，先坏的是根因”变成已教内容，1.6 才是复习而非首见。
4. **自检答案内联**（INS-09）：L108 的括号直接给答案，读者没有遮住的机会，与 L84 的检索设计不一致。

## 5. 章末掌握物

- L102 的掌握声明可操作：“对一份交接数据逐条回答 I1、I2、I4，并按交接时序确认 I3；说出它违反了哪条（可多条）不变量、根因是哪条。”它区分了“按内容回答”的三条与“按时序确认”的 I3，与 L43 一致。
- L104-L107 的四条要点覆盖三类数据、四条失败面、接缝、物理区间值与指针的区别，覆盖面合格。
- L108 的自检是一道迁移题（指针指向发送侧内存图），比复述题好。

缺口：

1. **缺三类数据的归类动作**（INS-16）：掌握声明直接从“对一份交接数据”开始，没有要求先判断它属于三类中的哪一类。1.1 的分类是本章第一个教学动作，应在掌握物里回收。
2. **检索被答案内联破坏**（INS-09）。
3. **根因/后果在 1.6 才首见**（INS-08），使掌握声明中的“根因”缺少教学支撑。

结论：掌握物齐备且大体可检验，修掉以上三点后与示例形成闭环。

## 8. 本章节序建议

### 8.1 建议顺序（推荐）

```
1.0 本章导读：问题入口 + 前置概念 + 本章不写什么
1.1 内核接手时拿到什么（三类数据）
1.2 四条通用不变量（表 → 一次提交/消费 → 三角色 → 物理指针 → I1 失败对照）
1.3 最小示例：四问走两遍
1.4 与后续篇章的接缝
1.5 本章回顾（小结 + 自检 + 术语）
```

理由：

- 1.0 吸收现 1.4 的“不写什么”，边界在阅读前交代，读者不会中途才发现某主题不在这里。
- 1.2 直接接 1.3，理论到练习零间隔；I4 的四个子检查、I3 的时序前提、三种角色都还在工作记忆里。
- 1.3 示例全用物理区间，不需要“高半”；把 1.4 接缝移到示例之后，消除虚拟地址概念对物理示例的干扰。
- 1.4 接缝在掌握物之前或之后都可；放在小结前，读者先知道“这些概念下一站去哪”，再收束本章。
- 1.5 回顾保持在章末，术语表继续作查阅入口。

### 8.2 需要同步改的交叉引用

- L7 的路线图：“第 1.5 节” → “第 1.3 节”。
- L59 的括注：“见 §1.6 术语” → “见 §1.5 术语”。
- L7/L63 对 §1.1、§1.2 的引用不变。
- 1.4 的列表并入 1.0 后，原 L63 的“本章的主干先回答……”一句改写为导读末句，避免出现指向已移动章节的“随后”。
