## 1. C 真序

### 1.1 阶段类型判定

判定为**服务事件循环型**，且形态特殊：input 不是自主主循环服务器，而是**以字符驱动框架（libchardriver）为外壳的事件路由服务**。① 不在 boot_image，由 `system.conf:400-403` 交 RS 拉起；② 进程主体在 `chardriver_task` 框架循环内（框架五判断）；③ input 只提供七槽回调（`input_tab`），其中六个业务 handler + 一个 `input_other`。

**7.18 N-07 错误路径**
- 主题：错误码与错误分支。
- 为什么重要：错误码必须映射 Minix3 的 errno，这是项目的硬约束，自造错误码会在跨模块调用处断裂。

**7.20 N-09 并发与同步**
