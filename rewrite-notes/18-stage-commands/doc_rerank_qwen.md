## 1. C 真序

### 1.1 阶段类型判定：集合型（命令集）+ 半条启动因果链

本 stage 同时具备两种特征，按提示词 §九"同一 stage 多种特征时说明按哪一类处理"：

- **01~05 是一段真正的线性交付因果链**（有运行时先后），按"启动链型"处理：内核交权 → init（PID 1）→ rc/rc.d → 拉服务 → getty/login → shell。这段的顺序 = 运行时序，可直接用 C 源码重建（下表）。
- **06~24 是并行命令集合**（328 个命令无彼此先后），按"驱动与命令集合型"处理：不强行排成一条线，而按功能域分组，组内给代表成员 + 差异表。

因此本 stage 的"真序"只存在于交付链（01→05），06~24 是围绕该链的并行体。**现有编号已经正确表达了这一结构**——`plan.md §2` 明确"编号 = 交付因果链阅读顺序；与实施顺序（§6）解耦"，实测文档编号 01~24 与因果链/功能域分组一致。
