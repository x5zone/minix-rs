# notes-layout.conf — 三棵笔记树的唯一路径真源

# 背景：notes/{rewrite,study,redesign} 伞布局已于 2026-10-07 迁移退役（见 rewrite-notes/MIGRATION.md），
# 规范路径从四节（伞目录/分区/模块层/阶段/文档）降为两节 {tree}/{stage}/{doc}.md。
# 工具链不再各自写死目录名：改布局只动本文件。
#
# 用法（bash）：
#   source "$(dirname "${BASH_SOURCE[0]}")/notes-layout.conf"
#   然后引用 $NOTES_TREE_REWRITE / $NOTES_TREES
#
# 状态目录键（2026-10-07 迁移定稿）：module 层随 fork-syscall-rewrite 一起退役，
# 由 {stage}（树根下第一级目录名，如 01-stage-kernel）顶替：
#   .review/{tool}/{stage}/{doc-stem}/     ← claude / codex
#   .review/{tool}/{stage}/scans/          ← trae
# 注意 {stage} 与覆盖率脚本的 --module（Minix3 模块名，如 kernel/vm/pm）是两个概念，不得混用。
