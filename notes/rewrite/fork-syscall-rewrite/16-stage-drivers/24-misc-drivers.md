# 24-misc-drivers：杂项驱动收尾

> **分类**：杂项（家家一件小事，状态页数公式各管一件）
> **源码**：`minix3/minix/drivers/printer/printer/printer.c`（四百二十四行的打印机）、`minix3/minix/drivers/eeprom/cat24c256/cat24c256.c`（五百零五行的存储器）、`minix3/minix/drivers/sensors/bmp085/bmp085.c`（五百八十三行的气压传感器）、`minix3/minix/drivers/examples/hello/hello.c`（一百五十八行的最小示例）与其余速览（见第 2.6 节矩阵，电源高级配置接口一百五十七文件八万三千二百七十九行系第三方移植）
> **Rust 模块**：`os/drivers/printer/printer/src/status.rs`（状态位与重试预算）、`os/drivers/eeprom/cat24c256/src/pages.rs`（分片与地址宽度）、`os/drivers/sensors/bmp085/src/convert.rs`（校准换算）
> **前置**：`notes/rewrite/fork-syscall-rewrite/16-stage-drivers/00-drivers-overview.md`（驱动子系统全景，杂项在其中的位置）、`notes/rewrite/fork-syscall-rewrite/16-stage-drivers/23-net-driver-variants.md`（变体查表思想对照）
> **说明**：杂项是全阶段收尾：家家只管一件小事（打印机看状态位，存储器切分片，传感器套公式，示例当课本）。本篇讲三家详例加余家矩阵，不重复讲各类别核心语义。端口总线流量在服务层，本库只定状态页数公式。

> **本篇不讲什么**：
> - 各类别核心语义（见第 05 到 23 篇，块字符网各归其位）
> - 第三方电源解析器全文（八万三千行移植代码，本篇只讲外壳与策略）
> - 总线硬件时序（本篇只讲驱动看到的接口，时序在服务层）
>
> 本篇只回答一个问题：**剩下的小驱动各自把哪一件小事做对**。

## 1. 概念：小卖部的三样货与一本课本

### 1.0 章节引言

目标读者是读完全部驱动文档的读者。前置知识只需要一条：驱动是独立进程，框架定钩子。本章解释杂项为什么值得收尾一篇：小事做不对，大事全白费。

### 1.1 打印机是看脸色的打字员

想象打字员：每打一字节先看老板脸色（状态字节）：健康色接着打，忙色等半秒再看，缺纸色停工要纸，离线色直接报错。等了一百二十次（约六十秒）还忙就不等了。脸色优先级铁律：缺纸压倒离线，离线压倒忙，忙压倒健康。

### 1.2 存储器是按页撕的便签本

存储器像便签本：读一次撕一百二十八字节，写一次撕十六字节（写多了跨页回绕，前功尽弃）。地址写一位还是两位看有没有页标志：有页标志写一位，没页标志写两位。本子共三万二千七百六十八 字节，三万二千七百六十八 除以分片就是总片数。

### 1.3 传感器是拿着对照表的化验员

传感器像化验员：芯片自带十一项体质系数（先读出来存好），测体温分两步（触发、等四千五百 微秒、读原始值），再套公式（中间值一二、合计值、缩放得十分之一度）。公式是数据手册写的，驱动只管抄对：抄错一位，零下四十度能算成撒哈拉。

### 1.4 示例是驾校的课本

最小示例是课本：打开计数、读到文件尾、限长、安全拷贝，三步走完就是字符驱动。主循环两行（本地启动加字符主循环），热升级存取各一函。新人照抄课本，改三处就是新驱动。

### 1.5 第三方解析器是请来的翻译团

电源高级配置接口是请来的翻译团（八万多行，二十多年历史）：只请翻译固件的那部分，Minix 外壳三文件（驱动入口、系统胶水、总线扫描）。策略只有一条：不逐行重写，只做外壳适配。翻译团内部怎么分工，本篇不管。

### 1.6 本章小结

杂项四件事：看脸色、撕便签、套公式、抄课本，外加请翻译团只包外壳。下一章进入 C 语言源码验证。

### 2.2 打印机状态位（`printer.c` 第四十六行到第五十二行，第二百零八行到第二百四十一行）

忙位十六进制十（第四十六行），健康位组合十六进制九十（第四十七行），掩码十六进制十一（第五十二行），缺纸位十六进制二十（第四十七行与第四十九行），在线位十六进制十（第四十七行），重试上限一百二十（第五十二行，半秒一次约六十秒）。完成检查 `output_done` 在第二百零八行到第二百四十一行：离线报输入输出错，缺纸报稍后重试，完则回执调用方。回调表 `printer_tab` 四项（第九十九行到第一百零三行）：打开 `printer_open`、写 `printer_write`、取消、中断。写路径 `printer_write` 在第一百六十行到第二百零三行（写中报输入输出错，非阻塞报稍后重试）。

### 2.3 存储器分片（`cat24c256.c` 第二百五十一行到第三百九十行，第四百二十七行到第四百二十八行）

读一片 `cat24c256_read128` 一百二十八 字节（第二百五十一行到第二百九十三行），读循环 `cat24c256_read` 步进一百二十八（第二百九十六行到第三百一十九行）。写一片 `cat24c256_write16` 十六字节（第三百二十二行到第三百六十四行），地址一位还是两位看无页标志（第三百四十二行到第三百五十行），写循环 `cat24c256_write` 步进十六（第三百六十七行到第三百九十行）。器件三万二千七百六十八 字节（第四百二十七行到第四百二十八行）。块外壳传输在第一百零六行到第一百三十五行。

### 2.4 传感器公式（`bmp085.c` 第十四行到第一百一十四行，第三百八十二行到第三百八十五 行）

触发命令与四档压力命令（第十四行到第三十五 行），校准寄存器从十六进制 AA 连读二十二字节（第九十行到第一百一十四行）。校准结构十一系数（第七十四行到第八十八行），读系数 `read_cal_coef` 在第二百一十三行到第三百零九行。体温换算在第三百八十二行到第三百八十五 行（中间值一二、合计值、缩放）。测量 `measure` 分两步（第三百一十七行到第四百一十八行）：触发、等、读原始值，体温压力各一套。

### 2.5 最小示例骨架（`hello.c` 第二十三行到第一百五十七行）

## 3. Rust 设计决策

> 本章解释为什么这样设计。每个决策先给依据，再给替代方案与取舍。

### 3.1 状态做成优先级读（依据：第 1.1 节、第 2.2 节）

缺纸先、离线次、健康比对再次、其余算忙，顺序即优先级。替代方案是位掩码一次判，不选的理由是：优先级顺序让缺纸压倒离线一次写对。

### 3.2 分片做成纯函数（依据：第 1.2 节、第 2.3 节）

读一百二十八 写十六各一函数，空传输返回空数组。替代方案是分片散落在传输入口，不选的理由同回环篇：纯函数一测就是全部。

### 3.3 地址宽度做成布尔函数（依据：第 1.2 节、第 2.3 节）

有页标志一位无页标志两位，一句话判完。替代方案是调用方各自算，不选的理由是：宽度收一处，改标志语义只改一处。

### 3.4 公式做成纯换算（依据：第 1.3 节、第 2.4 节）

校准加原始值进十分之一度出，中间值全用三十二位防溢出。替代方案是换算散落在测量里，不选的理由是：纯换算能拿数据手册例题验算（十五度整）。

### 3.5 设计决策汇总

| 决策 | 依据 | 替代方案 | 为何不选 |
|------|------|----------|----------|
| 状态优先级读 | 第 1.1、2.2 节 | 位掩码一次判 | 优先级写不对 |
| 分片纯函数 | 第 1.2、2.3 节 | 分片散落入口 | 边界测不全 |
| 宽度布尔函数 | 第 1.2、2.3 节 | 调用方各自算 | 改语义多处 |
| 公式纯换算 | 第 1.3、2.4 节 | 换算散落测量 | 例题验算不了 |

## 4. 错误处理

| 场景 | C 行为 | Rust 表达 | 说明 |
|------|--------|-----------|------|
| 缺纸 | 报稍后重试 | 缺纸态 | 先加纸 |
| 离线 | 报输入输出错 | 离线态 | 线没接好 |
| 忙超一百二十次 | 不再等 | 等待返回假 | 六十秒够了 |
| 空传输 | 无需分片 | 空数组 | 空车不上路 |
| 陌生芯片数据 | 告警 | 调用方判断 | 体质不对 |
