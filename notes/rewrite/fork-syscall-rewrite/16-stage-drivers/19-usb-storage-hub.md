## 1. 概念：挂号信的信封与小区的门卫

### 1.0 章节引言

目标读者是读完通用串行总线框架的读者。前置知识只需要两条：包有编号，设备枚举分五步。本章解释海量存储为什么需要包头包尾：批量端点只管搬运字节，不管这批字节是什么意思。

### 1.1 包头包尾是挂号信的信封

想象寄挂号信：信纸（小型计算机接口命令）装进信封（命令包头），信封上写着编号（标签）与收件要求（传输长度与方向）。邮局投递后，收信人回一张明信片（状态包尾），明信片上写着同样的编号与办理结果（成功、失败、阶段错乱）。寄信人对编号：明信片编号与信封编号一致且结果成功，这趟才算办完。

三段式是批量传输的全部怪癖：先发命令包头，再传数据（读是收，发是写），最后收状态包尾验标签。三段缺一段，传输就不算完。标签从一开始编号，每开一趟加一，上一趟的状态回来之前不开下一趟。

### 1.2 小型计算机接口命令是信纸的格式

信纸有固定格式：七种常用命令（测单元就绪、读、写、问询、读容量、要感知数据、读模式），每种命令规定了命令长度与数据长度（读容量命令十字节回八字节，问询命令六字节回三十六字节）。读写命令要求地址与长度按扇区分毫不差：五百一十二字节的整数倍，否则连信封都不封（传输守卫直接拒绝）。

### 1.3 集线器是小区的门卫

集线器像小区门卫：不管住户家里什么样，只看八个门口（最多八个端口）谁进谁出。门卫每秒巡逻一圈（轮询间隔一千毫秒），看到生人先让他复位报到（端口复位，最多试三次，每次等二百毫秒），报到成功登记入住（连上），搬走注销（断开），闹事拉黑（状态错永久标记坏，只有搬走能洗白）。

端口看法是集线器的全部怪癖：断开、连上、坏掉三态，生人到访连上，出走断开，状态错拉黑，通信错也拉黑。复位预算三计数，用完即拉黑。门卫自己不传数据，所以它既不挂块框架也不挂字符框架：只向上报告谁来了谁走了。

### 1.4 两份端点助手是同文的办事指南

海量存储与集线器各有一份端点助手（一百一十一行，同构）：配端点（号、方向、类型、包长、间隔），绑数据（数据包绑数据，建包绑八字节控制请求），阻塞提交（交包等信号量，回来验状态，比实际长度与期望长度）。同构不是巧合：两份指南抄的是同一份办事流程。

### 1.5 本章小结

海量存储三件事：信封装信纸，标签对明信片，扇区不对齐不寄。集线器一件事：看门口，八个，三态，三次复位。下一章进入 C 语言源码验证。

### 2.2 包签名与三段传输（`bulk.h` 第十三行到第四十二行，`usb_storage.c` 第二百三十行到第三百四十七行）

命令包签名 `CBW_SIGNATURE` 是十六进制四三四二五三五五（第十三行），状态包签名 `CSW_SIGNATURE` 是十六进制五三四二五三五五（第三十行），命令块长度十六字节（第十六行）。发命令包 `send_scsi_cbw_out` 在第二百三十行到第二百五十九行（`init_cbw` 初始化包头、标签自增、装命令、绑包头、阻塞提交验长度），收发数据在第二百六十六行到第三百一十一行，收状态包 `send_csw_in` 在第三百一十八行到第三百四十七行（`init_csw` 初始化包尾、收包、`check_csw` 核对标签签名状态）。标签配对靠当前标签 `current_cbw_tag` 与上一标签 `last_cbw_tag` 两个变量（第一百三十二行到第一百三十三行）。

### 2.3 七种小型计算机接口命令（`scsi.h` 第三十行到第一百二十七行，`scsi.c` 第三十一行到第二百八十八行）

命令码：测单元就绪 `TEST_UNIT_READY` 零、要感知数据 `REQUEST_SENSE` 三、问询 `INQUIRY` 十八、读容量 `READ_CAPACITY` 三十七、读 `READ_10` 四十、写 `WRITE_10` 四十二、读模式 `MODE_SENSE` 九十（第三十行到第三十六行）。各命令数据长度与命令长度在第三十八行到第五十七行（问询三十六配六，读容量八配十，读写十字节命令）。命令分发 `create_scsi_cmd` 在第三十一行到第五十七行，读写断言长度是扇区整数倍（第一百一十八行到第一百五十八行），问询回执解析 `check_inquiry_reply` 在第二百零三行到第二百二十九行（取厂商与产品名），状态核对 `check_csw` 查标签签名成功三项（第二百六十七行到第二百八十八行）。

### 2.4 块回调表与传输守卫（`usb_storage.c` 第一百零五行到第一百一十八行，第七百九十五 行）

海量存储注册块驱动表 `mass_storage`（第一百零五行到第一百一十八行）：类型磁盘，打开关闭传输输入输出控制清理分区几何七个回调，中断闹钟其他置空。传输守卫 `transfer_restrictions` 在第七百九十五 行：位置与字节数必须整除扇区大小。打开做探测 `try_first_open`（第一千一百四十五 行），传输按扇区分发读写（第一千二百五十二行），几何先读模式页（第一千四百七十六行）不行再按尺寸兜底（第一千五百零五 行：柱面等于尺寸除扇区，磁头六十四，每道三十二扇区）。

### 2.5 集线器端口管理（`usb_hub.c` 第四十七行到第五十六行，第三百九十行到第五百一十二行）

轮询间隔 `USB_HUB_POLLING_INTERVAL` 一千毫秒，端口上限 `USB_HUB_PORT_LIMIT` 八个，复位最多 `USB_HUB_MAX_TRIES` 三次，复位等待 `USB_HUB_RESET_DELAY` 二百毫秒（第四十七行到第五十六行）。端口任务循环 `hub_task` 在第三百九十行到第五百一十二行：等连上信号，`hub_get_descriptor` 取集线器描述符，端口数超八拒绝，逐口上电，然后死循环逐口 `hub_get_port_status` 查状态调变化处理，状态错断电永久拉黑，通信错挂起等摘除，尾睡一千毫秒。端口状态位域在第七十五 行到第九十八行，变化分类 `port_change` 五种在第一百四十一行到第一百五十八行（断开、连上、错三态加无变化与通信错）。

### 2.6 变化真值表与连上报到（`usb_hub.c` 第六百九十三行，第八百二十六行到第九百三十六行）

变化处理 `hub_handle_change` 是八行真值表（第六百九十三行）：先清变化位放行轮询，到访调连上，出走调断开，先走后到两个都调。连上报到 `hub_handle_connection` 在第八百二十六行：置端口复位，轮询复位完成位（最多三次每次睡二百毫秒），清复位位，要求连上且使能，译速度（低速高速全速），`ddekit_usb_info` 向上报告（第九百二十一行）。断开报告在第九百二十九行到第九百三十六行。

## 3. Rust 设计决策

> 本章解释为什么这样设计。每个决策先给依据，再给替代方案与取舍。

### 3.1 签名做成常量（依据：第 1.1 节、第 2.2 节）

两个签名写死（命令包头四三四二五三五五，状态包尾五三四二五三五五），验包先验签名再验标签最后验状态。替代方案是运行时读配置，不选的理由是：签名是协议写死的，读配置多一次错的机会。

### 3.2 标签做成配对器（依据：第 1.1 节、第 2.2 节）

开传输发新标签记下来，关传输三项全对才算成功（签名对、标签对、状态好），错项不消耗配对（传输还等着，复位恢复用得上），终局失败才放空。替代方案是裸计数器，不选的理由是：配对器把等谁的状态收敛到一处，错标签冒充回执不可能。

### 3.3 守卫做成纯函数（依据：第 1.2 节、第 2.4 节）

位置长度扇区对齐检查是纯算术（长度非零且两者整除扇区大小），测试不用起传输。替代方案是守卫散落在传输函数入口，不选的理由是：纯函数一测就是全部边界。

### 3.4 端口做成看法机（依据：第 1.3 节、第 2.5 节）

断开连上坏掉三态，到访出走状态错各走各的转移，拉黑后到访不洗白（只有出走能洗），复位预算三计数用完拉黑。替代方案是布尔加失败计数散写，不选的理由同存储篇：看法机让非法转移不可能。

### 3.5 设计决策汇总

| 决策 | 依据 | 替代方案 | 为何不选 |
|------|------|----------|----------|
| 签名常量 | 第 1.1、2.2 节 | 运行时读配置 | 协议写死 |
| 标签配对器 | 第 1.1、2.2 节 | 裸计数器 | 冒充回执可能 |
| 守卫纯函数 | 第 1.2、2.4 节 | 守卫散落入口 | 边界测不全 |
| 端口看法机 | 第 1.3、2.5 节 | 布尔散写 | 非法转移可能 |

## 4. 错误处理

| 场景 | C 行为 | Rust 表达 | 说明 |
|------|--------|-----------|------|
| 签名不对 | 包不认 | 关闭返回假且不消耗配对 | 信封错不拆 |
| 标签不对 | 回执不认 | 关闭返回假且不消耗配对 | 冒充不受理 |
| 状态失败 | 复位恢复 | 关闭返回假但放空配对 | 终局失败走恢复 |
| 阶段错乱 | 复位恢复 | 关闭返回假但放空配对 | 终局失败走恢复 |
| 长度为零 | 拒绝传输 | 守卫返回假 | 空车不上路 |
| 地址不对齐 | 拒绝传输 | 守卫返回假 | 扇区分毫不差 |
| 长度不对齐 | 拒绝传输 | 守卫返回假 | 扇区分毫不差 |
| 端口状态错 | 断电拉黑 | 看法转坏掉 | 闹事拉黑 |
| 复位超三次 | 宣告坏掉 | 复位返回假 | 预算用完 |
| 拉黑后到访 | 不洗白 | 看法保持坏掉 | 拉黑不返聘 |
