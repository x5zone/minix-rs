## 1. 概念：五个怪癖各管一件闲事

### 1.0 章节引言

目标读者是读完真盘两兄弟的读者。前置知识只需要一条：命令超时了就复位。本章解释五个变体为什么不能共用一套代码：每个变体都多管了一件闲事，闲事不同，顺序就不同。

### 1.1 软盘是年迈的磁带录音机

想象一台年迈的磁带录音机：磁头会偏（读错了要重试），偏多了要重新校准（磁头归零再找道），实在读不出就认栽（超过六次报错）。软盘驱动就是这台录音机的管理员：七组驱动介质组合（常用四种介质：三百六十千字节、七百二十千字节、一点二兆字节、一点四四兆字节，一点四四兆每磁道十八扇区）。

重试策略是软盘的全部怪癖：单次失败先看能不能重试（写保护这类错误重试也没用，直接认栽），能重试就计数，数到六次认栽，数到三次先重新校准磁头再继续。校准是中场休息，不是认输：校准完错误计数不清零，接着数。

### 1.2 闪存卡是排队考试的考生

闪存卡像考生排队考试：先喊到（复位进空闲），再查准考证（轮询工作条件），再报身份证号（取卡标识），再点名入座（选中卡），再发考卷（切高速模式、定块长度），考卷到手才能答题（读写命令）。顺序错一步，卡就不理人。

上电顺序是闪存卡的全部怪癖：新生、轮询条件、识别身份、配置参数、就绪五个阶段，每个阶段只认一条命令。乱序的成功不算成功：没轮询完就报身份，状态机拒绝推进。块长度固定谈成五百一十二字节，之后读写都按这个尺寸来。

### 1.3 故障注入盘是专门捣乱的替身演员

故障注入盘不存数据，它是替身演员：观众（上层文件系统）的每个请求，它都原样转交给真正的演员（下层驱动），但在转交前、转交中、转交后三个时机按剧本捣乱（改数据、报错、送错地址、丢半截写）。剧本就是规则：地址范围命中哪条规则，就按那条规则在三个拦截点各做什么动作。

三个拦截点是故障注入盘的全部怪癖：前拦截点在请求到达下层之前动手，中拦截点代替下层动手，后拦截点在下层回答之后动手。不在规则地址范围内的请求直接放行，一个字节都不碰。

### 1.4 过滤盘是仓库质检员兼双保险

过滤盘像仓库质检员：每八个扇区算一次校验和存起来（九个扇区一组，八个数据加一个校验），读出来先验货再交货，验货失败按策略办（报错或者照常交货但记一笔）。同时它还买双保险：同一份数据写两份（镜像），一份验货失败就读另一份，失败次数多了就把坏的那份开除（连续失败三次摘除）。

分组校验与镜像摘除是过滤盘的全部怪癖：校验和种类有四种（无、异或、循环冗余、消息摘要），组布局固定八加一，镜像成员失败计数到三摘除。摘要数学与传输流量在服务层，本库只管哪种校验、何时摘除。

### 1.5 回环盘是把文件当磁盘的翻译

回环盘像翻译：上层说扇区读写，它翻译成文件读写。一次大传输拆成多次小搬运（每次最多六万五千五百三十六字节），写完落盘（强制同步，保证掉电不丢）。文件本身没有几何参数（柱面磁头扇区）时，它按扇区总数现编一套（大文件用六十四磁头三十二扇区，小文件用单磁头单扇区）。

分块搬运与几何现编是回环盘的全部怪癖：拆块是纯算术（剩余字节与块上限取小），几何推导是纯查表（够大就用大布局，不够大就用最小布局）。文件描述符流量在服务层，本库只管拆几块、编什么几何。

### 1.6 本章小结

五个变体五个怪癖：软盘数错误数到六认栽，闪存卡按顺序考试，故障注入盘按剧本捣乱，过滤盘验货加双保险，回环盘翻译扇区为文件。下一章进入 C 语言源码验证。

### 2.9 与 C 一万零四十九行的差异说明

| 差异 | C 做法 | Rust 做法 | 分类 |
|------|--------|-----------|------|
| 硬件流量 | 软盘命令、主机寄存器全实现 | 只定顺序 | 设计决策：硬件流量在服务层 |
| 传输搬运 | 边传边搬边验 | 服务层事件 | 设计决策：搬运在服务层 |
| 摘要数学 | 循环冗余与消息摘要全实现 | 服务层 | 设计决策：数学在服务层 |
| 中断等待 | 中断处理全实现 | 服务层 | 设计决策：中断在服务层 |

## 3. Rust 设计决策

> 本章解释为什么这样设计。每个决策先给依据，再给替代方案与取舍。

### 3.1 密度做成静态表（依据：第 1.1 节、第 2.3 节）

七组驱动介质组合取四组同驱同介质行写成编译期常量数组（非常用交叉行不建模，时序参数归服务层），块总数纯算术（每磁道扇区数乘柱面数乘双面磁头数）。替代方案是运行时从驱动读配置，不选的理由是：组合只有七组且永不变化，静态表让非法规格不可能。

### 3.2 重试做成计数器（依据：第 1.1 节、第 2.3 节）

错误计数加动作枚举（重试、校准后重试、认栽），不可重试的错误一次就认栽且不计数。替代方案是布尔加循环散写，不选的理由是：计数器把六次与三次两个阈值收敛到一处，改阈值只改一处。

### 3.3 上电做成阶段机（依据：第 1.2 节、第 2.7 节）

新生轮询识别配置就绪五态，每态只认一条命令，乱序成功拒绝推进。替代方案是布尔三元组，不选的理由同真盘篇：阶段机让非法转移不可能。

### 3.4 规则做成地址区间（依据：第 1.3 节、第 2.4 节）

规则是地址前闭后开区间加三个拦截点各一个动作，查找取第一条命中的规则。替代方案是哈希表按块号精确匹配，不选的理由是：故障注入按地址范围剧本写，区间匹配贴合剧本写法。

### 3.5 校验与镜像做成策略（依据：第 1.4 节、第 2.5 节）

校验种类四值枚举，组布局固定八加一，镜像健康计数到三摘除。替代方案是策略散落在传输函数里，不选的理由是：策略集中后测试不用起传输，一测就是全部。

### 3.6 回环做成纯布局（依据：第 1.5 节、第 2.6 节）

拆块返回每步长度数组，几何推导按扇区数查表，大文件大布局，小文件最小布局。替代方案是布局里直接读写文件，不选的理由是：读写文件要描述符，描述符在服务层，布局只认数字。

### 3.7 设计决策汇总

| 决策 | 依据 | 替代方案 | 为何不选 |
|------|------|----------|----------|
| 密度静态表 | 第 1.1、2.3 节 | 运行时读配置 | 组合七组永不变 |
| 重试计数器 | 第 1.1、2.3 节 | 布尔加散写 | 阈值收一处 |
| 上电阶段机 | 第 1.2、2.7 节 | 布尔三元组 | 非法转移可能 |
| 规则地址区间 | 第 1.3、2.4 节 | 哈希精确匹配 | 剧本按范围写 |
| 校验镜像策略 | 第 1.4、2.5 节 | 策略散落传输 | 测试不用起传输 |
| 回环纯布局 | 第 1.5、2.6 节 | 布局读写文件 | 描述符在服务层 |

## 4. 错误处理

| 场景 | C 行为 | Rust 表达 | 说明 |
|------|--------|-----------|------|
| 写保护失败 | 不重试 | `GiveUp` 且计数为零 | 重试也没用 |
| 错误数满六次 | 放弃传输 | `GiveUp` | 录音机认栽 |
| 错误数到三次 | 先校准再继续 | `RecalibrateAndRetry` | 中场休息不清零 |
| 上电乱序成功 | 不推进 | `note_success` 返回假 | 顺序错不算数 |
| 就绪后再成功 | 无下一态 | `note_success` 返回假 | 到头了 |
| 规则地址越界 | 不命中 | `find_rule` 返回空 | 范围外放行 |
| 镜像失败满三次 | 摘除成员 | `is_live` 返回假 | 坏份开除 |
| 摘除后再失败 | 保持摘除 | `record_failure` 返回真 | 开除不返聘 |
| 传输长度为零 | 无需搬运 | 空数组 | 空车不上路 |
| 小文件无几何 | 最小布局 | 单磁头单扇区 | 现编一套 |
