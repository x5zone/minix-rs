# 实现路线图

## 1. 阶段总览

| 阶段 | 名称 | 涉及服务 | 目标 | 代码量 | Mock 范围 |
|-----|------|---------|------|--------|----------|
| 1 | MProc 结构体与进程表基础 | PM | 建立 PM 进程管理的数据基础 | ~150 行 | 无 |
| 2 | do_fork 核心逻辑（上） | PM | 参数检查与槽位分配 | ~200 行 | 无 |
| 3 | PID 生成器 | PM | 实现 PID 分配与冲突检测 | ~100 行 | 无 |
| 4 | do_fork 核心逻辑（下） | PM | 进程结构复制与初始化 | ~200 行 | 无 |
| 5 | PM 调用 VM Fork | PM→VM | 通过真实 IPC 调用 VM fork 服务 | ~100 行 | 无（IPC 真实） |
| 6 | PM 调用 VFS Fork | PM→VFS | 通过真实 IPC 调用 VFS fork 服务 | ~100 行 | 无（IPC 真实） |
| 7 | VM Fork 实现 | VM | 地址空间克隆与 CoW 设置 | ~300 行 | MMU、物理内存访问 |
| 8 | VFS Fork 实现 | VFS | 文件描述符复制与引用计数 | ~250 行 | 磁盘 I/O |
| 9 | Kernel Fork 实现 | Kernel | PCB 克隆与 Endpoint 生成 | ~250 行 | 硬件寄存器、时钟 |
| 10 | SCHED Fork 实现 | SCHED | 调度参数继承与 CPU 选择 | ~100 行 | 无 |
| 11 | 跨服务协调 | PM/VM/VFS/Kernel/SCHED | 完整 fork 状态机实现 | ~300 行 | 无 |
| 12 | 集成测试 | 全部 | 端到端验证与性能测试 | ~200 行 | 无 |

## 2. 里程碑定义

### Milestone 1: PM 基础完成（阶段1-4）
- **时间**: 第 1-2 周
- **标志**: PM 层可独立完成进程创建（Mock VM/VFS/Kernel）
- **交付物**: 
  - MProc 结构体与进程表
  - do_fork 完整实现
  - PID 生成器

### Milestone 2: 单层服务完成（阶段5-7）
- **时间**: 第 3-4 周
- **标志**: VM/VFS/Kernel 各自实现 fork 逻辑
- **交付物**:
  - VM 地址空间克隆
  - Kernel PCB 克隆
  - VFS 文件描述符复制

### Milestone 3: 跨服务协调完成（阶段8）
- **时间**: 第 5 周
- **标志**: 完整 fork 系统调用可正常工作
- **交付物**:
  - PM 状态机实现
  - 跨服务消息协议
  - 错误回滚机制

### Milestone 4: 集成验证完成（阶段9）
- **时间**: 第 6 周
- **标志**: 所有测试通过，性能达标
- **交付物**:
  - 端到端测试套件
  - 性能基准测试
  - 文档完善

## 4. 验收标准

### 功能验收
- [ ] fork 系统调用可成功创建子进程
- [ ] 子进程获得正确的 PID 和 Endpoint
- [ ] 父子进程共享地址空间（CoW）
- [ ] 文件描述符正确继承（引用计数递增）
- [ ] 错误情况下资源正确回滚

### 性能验收
- [ ] fork 延迟 < 1ms（Mock 环境）
- [ ] 内存占用增长 < 10%（CoW 机制有效）
- [ ] 1000 次连续 fork 无内存泄漏

### 代码质量验收
- [ ] 单元测试覆盖率 > 80%
- [ ] 所有 Clippy 警告修复
- [ ] 文档注释完整

## 5. 风险与缓解

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|---------|
| 索引对齐错误 | 中 | 高 | 使用 SlotIndex 类型封装，编译期检查 |
| 引用计数泄漏 | 中 | 高 | 实现 Drop trait，添加泄漏检测测试 |
| 状态机死锁 | 低 | 高 | 超时机制，状态机可视化验证 |
| VM CoW 实现复杂 | 高 | 中 | 分阶段实现，先简化后优化 |
