## 1. C 真序

### 1.1 阶段类型判定

**服务事件循环型**。IPC server 是一个用户态服务进程，运行时序分两段：启动段（SEF 注册 → MIB 子树挂载 → 进入主循环）和循环段（收信 → 分类 → 分发 → 回信/挂起 → 收尾清拍）。不存在跨 stage 的线性启动链（它不是被其它服务一步一步拉起的），也不存在大规模并行集合（只有七个系统调用）。

## 4. 新目录

### 4.1 结论：维持现有 12 篇结构

经过完整的 C 源码审阅与知识点池对照，**现有 12 篇结构（00~10 + 99）在以下四个硬标准上全部达标**：
