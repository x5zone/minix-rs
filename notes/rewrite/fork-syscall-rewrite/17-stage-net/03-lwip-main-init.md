# 03-lwip-main-init：轻量服务骨架

> **分类**：服务骨架（十三步上楼，四路分岔口，建户按域分）
> **源码**：`minix3/minix/net/lwip/lwip.c`（三百八十二行的启动链与主循环）、`minix3/minix/net/lwip/mibtree.c`（一百四十一行的管理树注册）
> **Rust 模块**：`os/net/lwip/src/startup.rs`（启动阶段机与分发道路）、`os/net/lwip/src/server.rs`（主循环、传输接缝、道路分发）、`os/libs/minix-netdriver/src/service.rs`（两服务共用的到达分类器）
> **前置**：`notes/rewrite/fork-syscall-rewrite/17-stage-net/01-sockdriver-framework.md`（套接字框架，十七请求）、`notes/rewrite/fork-syscall-rewrite/17-stage-net/02-sockevent-framework.md`（事件框架，对象与续作）
> **说明**：轻量骨架是两框架第一次完整消费：启动链十三步一步登天，主循环四路分岔各走各。本篇讲上楼顺序与分岔口，不讲各房间内部。各模块实现与消息流量在服务层，本库只定顺序与道路。

> **本篇不讲什么**：
> - 各模块内部实现（见第 04 到 20 篇，池工具族接口路由各归其位）
> - 管理库服务端（见第十阶段管理库面，本篇只讲注册时序）
> - 消息发送流量（本篇只讲顺序与道路，流量在服务层）
>
> 本篇只回答一个问题：**服务起来先干哪十三件事，信进来走哪条路**。

## 1. 概念：十三层大楼与四岔路口

### 1.0 章节引言

目标读者是读完两框架的读者。前置知识只需要三条：十七种请求，对象住哈希，没办完写留言条。本章解释服务骨架为什么先讲：十三步是全阶段文档的锚点，每一步都是一篇后续文档。

### 1.1 启动链是十三层大楼

想象盖十三层大楼：播随机种子（打地基），请协议栈库进场（搭架子），请事件库进场并登记建户回调（装电梯），请三个小工（内存池、序号、组播），请四个大户（网际、传输、数据、原始套接字），请三界面（接口对象、环回、以太网），请网卡模块，请求路由两低户（路由套接字、链路套接字），请路由，请求过滤设备，请管理树登记（封顶），请默认配置（装修），定闹钟开门营业。错一层，楼就歪。

### 1.2 主循环是四岔路口

开门营业后，门口是个四岔路口：先扫环回队，再看闹钟，再收信。信分四路：通知路（时钟到点响铃，设备上下线查网卡）、管理路（管理库查询转交）、套接字路（套接字请求交事件框架，字符块请求交过滤设备）、网卡回执路（驱动答复交网卡模块）。陌生信登记在案直接扔掉（打日志丢弃）。

### 1.3 建户按域分诊台

建户是分诊台：第四版网际协议进流诊室（流走传输、包走数据、裸走原始，裸号要看超级用户牌），第六版同理（条件编译守门），路由号进路由诊室，链路号进链路诊室，挂错号直接退号（报域不支持）。分诊错了，后面全错。

### 1.4 随机数是防重号的摇号机

随机数只干两件事：传输控制块初端口防重启重号，组播定时抖动。摇号机不用真随机：播一次种子，摇一辈子。种子取自启动时钟，注释写得明明白白。

### 1.5 管理树登记是封顶仪式

管理树登记是封顶：各模块先把自己的子树报上来（按协议排序，超六个断言），封顶时一次注册三棵（网际、网际六、管理本机），注册不上直接崩（远端失败静默忽略，本地失败才崩）。封顶必须在所有上报之后：顺序错了，树就缺枝。

### 1.6 本章小结

服务骨架三件事：十三步上楼，四路分岔，分诊建户。下一章进入 C 语言源码验证。

### 2.3 主循环四路（`lwip.c` 第三百零一行到第三百七十九行）

循环前置：扫环回队 `ifdev_poll`（第三百零七行），看闹钟 `check_lwip_timer`（第三百一十五 行），收信 `sef_receive_status`（第三百一十七行，中断继续他错崩溃在第三百一十八行到第三百二十一行）。通知路在第三百二十五行（时钟 `expire_timers` 响铃在第三百二十八行，设备上下线 `ndev_check` 查网卡在第三百三十四行）。管理路在第三百四十七行（转管理库 `rmib_process` 处理在第三百四十八行）。套接字路在第三百五十二行（套接字请求交 `sockevent_process` 事件处理在第三百五十五 行，字符块请求交 `bpfdev_process` 过滤设备在第三百六十二行）。网卡回执路在第三百六十八行默认分支内（网卡响应交 `ndev_process` 网卡处理在第三百七十一行，陌生打日志丢弃在第三百七十六行到第三百七十七行）。

### 2.3.1 Rust 主循环的到达分类（`os/net/lwip/src/server.rs`，`os/libs/minix-netdriver/src/service.rs`）

主循环本体在 `server.rs` 的 `run` 函数：**`sef_startup` 的握手半先行**——等 RS 的 `SEF_INIT` 通知（`CALL_NOTIFY` 加 `RS_INIT` 号）到达、回 OK 给 RS，服务才算加载完成；握手期间的其他到达照意外路丢弃。之后启动链走满七步才放行第一封消息（`Startup` 阶段机做门），循环内先问处理器还要不要跑（SYSTEM 通知把终止旗标置位，信号即停），再经 `minix-sef` 的 `sef_receive_status` 收信——PIN 送回、信号上报、普通消息落到四条路上。分类规则由 `minix-netdriver` 的 `classify` 承担，与 C 同序：来源端点优先（时钟走到期、数据存储走驱动上下线、MIB 走管理路、VFS 走设备分诊），类型判定其次（套接字设备范围、过滤器设备的字符块范围、网卡回复范围）。两处与 C 的刻意差异都记录在案：非时钟非数据存储的通知在 C 里走默认分支打日志，Rust 侧同位就是 `unexpected` 路（不另设路）；传输连续三次损坏时循环带错误退出，C 侧同位是 panic——退出与崩溃对服务管理器是同一件事的两说。每条路的实现体挂在 `NetHandler` 特征上，生产类型在 `main.rs`，测试用脚本化传输与记录型处理器（IPC 服务器的既有形状）。

### 2.4 分诊四域（`lwip.c` 第一百五十一行到第一百九十行）

建户回调 `alloc_socket` 在第一百五十一行到第一百九十行。第四版网际在第一百五十七行（流走 `tcpsock_socket` 传输在一百六十三行，包走 `udpsock_socket` 数据在一百六十六行，裸先看超级用户牌在一百六十九行到一百七十行，不认报原型不支持在一百七十五 行，否则走 `rawsock_socket` 原始在一百七十二行）。第六版同理（条件编译守门）。路由号走 `rtsock_socket` 路由套接字（第一百七十九行），链路号走 `lnksock_socket` 链路套接字（第一百八十二行），挂错号报域不支持（第一百八十八行，注释称误配置）。

### 2.5 随机数与管理树（`lwip.c` 第一百二十六行到第一百四十三行，`mibtree.c` 全文件）

随机钩子 `lwip_hook_rand` 在第一百二十六行到第一百四十三行（返回伪随机，注释称仅防重号加抖动）。管理树三静态节点（第十四行到第三十二行：网际、网际六、管理本机），容量六协议四管理（第十二行与第二十六行）。登记 `mibtree_init` 在第三十九行到第六十九行（键在第四十二行到第四十六行，三次 `rmib_register` 注册失败崩溃在第五十八行到第六十八行，远端失败静默）。上报接口 `mibtree_register_inet` 在第七十六行到第一百一十九行与 `mibtree_register_lwip` 在第一百三十行到第一百四十一行（按协议排序插，超容断言，错域崩溃）。

## 3. Rust 设计决策

> 本章解释为什么这样设计。每个决策先给依据，再给替代方案与取舍。

### 3.1 启动做成阶段机（依据：第 1.1 节、第 2.2 节）

新生库就绪框架就绪户就绪接口就绪低户就绪管理就绪运行八态，成功推进一步，运行后再推拒绝。替代方案是布尔三元组，不选的理由同存储篇：阶段机让非法转移不可能。

### 3.2 分发做成道路枚举（依据：第 1.2 节、第 2.3 节）

通知管理套接字网卡回执陌生五变体，陌生也占一位（显式丢弃）。替代方案是条件分支链散写，不选的理由是：枚举让漏道路编译不过，陌生有专位。

### 3.3 域做成枚举（依据：第 1.3 节、第 2.4 节）

四域各一变体，裸号权限纯函数。替代方案是裸数字传域号，不选的理由是：枚举让挂错号不可能（退号变体必处理）。

### 3.4 设计决策汇总

| 决策 | 依据 | 替代方案 | 为何不选 |
|------|------|----------|----------|
| 启动阶段机 | 第 1.1、2.2 节 | 布尔三元组 | 非法转移可能 |
| 道路枚举 | 第 1.2、2.3 节 | 条件分支散写 | 漏道路不响 |
| 域枚举 | 第 1.3、2.4 节 | 裸数字传域 | 挂错号可能 |

## 4. 错误处理

| 场景 | C 行为 | Rust 表达 | 说明 |
|------|--------|-----------|------|
| 运行后再推 | 无下一态 | 推进返回假 | 到头了 |
| 未运行就循环 | 不许 | 运行检查返回假 | 楼没盖好不开门 |
| 陌生信 | 打日志丢弃 | 陌生变体 | 陌生有专位 |
| 裸号无超级用户身份 | 报访问拒绝 | 权限返回假 | 裸号看牌 |
| 挂错域 | 报域不支持 | 调用方拒绝 | 挂错退号 |
