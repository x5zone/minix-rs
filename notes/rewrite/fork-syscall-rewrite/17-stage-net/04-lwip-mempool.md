# 04-lwip-mempool：缓冲池与链工具

> **分类**：资源第 1 篇（五百一十二一切，池空报无缓冲，链工具只定算法）
> **源码**：`minix3/minix/net/lwip/mempool.c`（八百二十一行的定制池实现）、`minix3/minix/net/lwip/pchain.c`（一百五十四行的链工具）、`minix3/minix/lib/liblwip/lib/lwipopts.h`（第四十九行缓冲尺寸，第二十九行到第八十一行池开关）
> **Rust 模块**：`os/net/lwip/src/mempool.rs`（分片尺寸与统计）
> **前置**：`notes/rewrite/fork-syscall-rewrite/17-stage-net/03-lwip-main-init.md`（轻量骨架，内存池初始化是第四步）
> **说明**：内存池是资源赛道的第一篇：标准池关掉不用，定制池五百一十二一切，池空了上层报无缓冲。本篇讲分片尺寸与耗尽映射，不讲协议栈内部缓冲语义。池存储与链流量在服务层，本库只定尺寸与映射。

> **本篇不讲什么**：
> - 协议栈内部缓冲语义（见 `24-liblwip-port.md`，第三方栈另讲）

> - 池存储实现（本篇只讲尺寸与映射，存储在服务层）
>
> 本篇只回答一个问题：**缓冲切多大，池空了上层报什么**。

## 1. 概念：食堂的餐盘与洗碗池

### 1.0 章节引言

目标读者是读完服务骨架的读者。前置知识只需要一条：内存池初始化是启动链第四步。本章解释定制池为什么存在：标准池的盘子尺寸不对，得自己定一套。

### 1.1 分片是统一尺寸的餐盘

食堂餐盘统一五百一十二 字节：菜多了一盘装不下就加盘（链化），菜太长连盘带菜装不下就拒收（超长连续分配不支持）。小菜另有小碟（包头专用小块），大菜走大盘（数据块），特大菜（超五百一十二连续）直接说没有。盘子尺寸写死在配置里，改一处全池跟着变。

### 1.2 统计是洗碗池的水位尺

水位尺两格：当前在外多少盘子，历史最高多少盘子。上层看尺定量（发送队列上限取当前四分之三，断言接收不超当前）。尺子只读不写：读数的人不管洗碗，洗碗的人不管读数。

### 1.3 链工具是串盘子的签子

链工具两把签子：找尾（顺链走到尾，返回尾下一格地址，包队列友好），估量（按五百一十二上舍入估块数，首块固定计五百一十二防藏头）。签子只算不搬：搬运在服务层。

### 1.4 耗尽是没盘子的回话

没盘子有三种回话：数据报层报无缓冲，原始层报无缓冲（小包直接扔），过滤设备层报内存不够（释首块接着干），接口层停收本轮（发包记丢包加内存错）。回话不同，病根一样：池空了。池空不崩服务：崩的是当次请求，不是服务。

### 1.5 容量是十七兆的由来

池上限默认六十四板：推导式写在注释里（两方向缓冲乘套接字数除以每板字节），约十七兆。板用完可再铺（铺板失败节流等下轮），退板留最后一块（全退光下次还得铺）。铺板走预分配映射，失败首板崩余板等。

### 1.6 本章小结

内存池四件事：盘子五百一十二，尺子两格，签子两把，没盘子好言回绝。下一章进入 C 语言源码验证。

## 3. Rust 设计决策

> 本章解释为什么这样设计。每个决策先给依据，再给替代方案与取舍。

### 3.1 尺寸做成常量（依据：第 1.1 节、第 2.2 节）

五百一十二写死，多处推导共用。替代方案是运行时读配置，不选的理由是：尺寸是编译期契约，读配置多一次错的机会。

### 3.2 分片做成纯函数（依据：第 1.1 节、第 2.4 节）

总数进数组出，空总数返回空。替代方案是分片散落在分配入口，不选的理由同回环篇：纯函数一测就是全部。

### 3.3 压力做成比例判（依据：第 1.2 节、第 2.3 节）

当前乘四超限乘三即压力，整数运算无浮点。替代方案是浮点比值，不选的理由是：无标准库浮点，整数比例一次写对。

### 3.4 设计决策汇总

| 决策 | 依据 | 替代方案 | 为何不选 |
|------|------|----------|----------|
| 尺寸常量 | 第 1.1、2.2 节 | 运行时读配置 | 编译期契约 |
| 分片纯函数 | 第 1.1、2.4 节 | 分片散落入口 | 边界测不全 |
| 压力比例判 | 第 1.2、2.3 节 | 浮点比值 | 无浮点库 |

## 4. 错误处理

| 场景 | C 行为 | Rust 表达 | 说明 |
|------|--------|-----------|------|
| 池空数据报 | 报无缓冲 | 调用方映射 | 池空不崩服务 |
| 池空原始 | 报无缓冲或丢包 | 调用方映射 | 小包直接扔 |
| 池空过滤 | 报内存不够 | 调用方映射 | 释首块接着干 |
| 非法释放 | 崩溃 | 调用方断言 | 错放必崩 |
| 空总数分片 | 无需分片 | 空数组 | 空车不上路 |
