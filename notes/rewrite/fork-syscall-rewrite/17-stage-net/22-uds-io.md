## 1. 概念：收发共用一个环，数据与元数据交织

### 1.0 本章的读者与阅读方法

本章假设读者已经理解第 21 篇的 5 种状态，知道连接中与已连接的区别。本章不需要读者了解文件描述符表，只需要带着四个问题来读：接收缓冲有多大，环形位置如何推进，段有哪几种，附带数据的上限是多少。读完本章，读者应当能够说出 32768、4096、5 三个数字的含义，4 种段类型的名称，以及三种套接字类型的边界差异，即使遮住所有函数名字也不影响理解。

### 1.1 只有接收缓冲，大小 32768 且为页大小倍数

每个套接字没有发送缓冲，只有一个接收缓冲，大小 32768 字节。缓冲在使用时映射，不用时释放。大小取页大小倍数，避免浪费。数据与元数据交织存放：普通字节、长度、源地址、发送者凭据混在同一个环里，因此实际可传输的数据通常小于 32768。头文件注释明确警告：超过 65535 需要改多个字段宽度，说明当前字段宽度是按 32768 设计的。这种单缓冲的设计与网络套接字的双缓冲形成对照：本机通信不需要拥塞控制，发送方可以直接写入接收方的环，省掉一次拷贝。Linux 内核同样为本地域套接字采用单接收缓冲加直接写入，Redox 系统把本地域通道实现为有界环形队列，思路一致。

### 1.2 环形推进用取余，空闲用饱和减法

环形位置推进为当前位置加步数后对缓冲尺寸取余，回到开头自动绕回。空闲字节为总数减去已用，已用超限时饱和为 0 而不是回绕成大数。可用载荷为总数减去头部长度，头部 5 字节。偏移断言要求偏移小于总数，否则是调用者错误。这些纯算术的意义在于无分支的正确性：取余与饱和减法对所有输入都有定义，不需要调用者预检，测试只需要传入边界数字即可覆盖。

### 1.3 段分 4 种，附带数据分两类

一个段可以只含普通数据，或只含附带数据，或两者都有，或两者都无的纯标记。附带数据有两类：在途文件描述符队列（按段成组，首对象的计数记录组大小，其余为 0）与发送者凭据。单次附带数据不得超过 4096 字节。控制缓冲与描述符数组都是静态分配，大小同样受该上限约束。凭据长度按组数动态计算，组越多凭据越长，发送前按剩余空间截断最小需求，保证头部加凭据之后仍有空间放数据。

### 1.4 三种套接字类型的边界语义不同

流式套接字是字节流，无消息边界，接收方可以任意长度读取。顺序包套接字保留消息边界，一次读取恰好一条消息。数据报套接字无连接，每条消息独立寻址。三种类型的缓冲段解释相同，但读取时的截断与唤醒条件不同。悬挂续作在缓冲不足时挂起，条件满足时恢复，与通用框架的续作机制共用同一入口。

### 1.5 本章小结

数据面解决四件事：32768 的单接收缓冲，取余推进与饱和空闲的算术，4 种段类型加两类附带数据，三种类型的边界差异。下一章进入 C 语言源码的逐项验证，确认每个数字都有源码依据。

## 3. Rust 设计决策

> 本章解释每个设计选择的原因，先给出依据，再列出考虑过的替代方案与放弃理由。

### 3.1 环形算术采用取余与饱和减法（依据：第 1.2 节、第 2.2 节）

推进取余，空闲饱和。替代方案是调用者预检后做普通减法。放弃的理由是预检把责任推给调用者，遗漏预检即回绕错误，而饱和减法对所有输入都有定义。

### 3.2 段类型采用四变体枚举（依据：第 1.3 节、第 2.2 节）

数据、控制、两者、空标记各为一个变体。替代方案是用两个布尔量。放弃的理由是两个布尔量有 4 种组合但含义需要查表，而枚举让每种组合有名字，匹配缺分支会编译失败。

### 3.3 上限采用具名常量（依据：第 1.1 节、第 1.3 节、第 2.2 节）

缓冲、控制、头部各有一个名字。替代方案是使用处手写数字。放弃的理由是手写数字无法区分 4096 是控制上限还是其它含义，重构时容易改错。

### 3.4 设计决策汇总

| 决策 | 依据章节 | 考虑过的替代方案 | 放弃理由 |
|------|----------|------------------|----------|
| 取余饱和算术 | 第 1.2 节、第 2.2 节 | 调用者预检 | 遗漏预检即回绕 |
| 段四变体枚举 | 第 1.3 节、第 2.2 节 | 两个布尔量 | 含义需查表 |
| 上限具名常量 | 第 1.1 节、第 2.2 节 | 使用处手写数字 | 含义不清，重构易错 |

## 4. 错误处理

| 场景 | C 语言行为 | Rust 表达 | 说明 |
|------|------------|-----------|------|
| 控制长度超过 4096 | 拒绝收发 | 上限函数返回假 | 超出不接受 |
| 偏移达到缓冲总数 | 断言失败 | 调用者保证，算术本身全定义 | 偏移越界属调用错误 |
| 已用超过总数 | 不可能，防御性饱和 | 空闲函数返回 0 | 超限不回绕 |
