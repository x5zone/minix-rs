# 20 — 整表快照和单进程快照：进程文件系统要的两份数据

> **分类**: 进程信息 / 进程文件系统那一端
> **源码**: `minix3/minix/servers/mib/proc.c:1177-1211`（整表 `mib_minix_proc_list`）、`:1217-1288`（单进程 `mib_minix_proc_data`）、`minix3/minix/include/minix/sysctl.h:58-88`（两结构和两组标志）
> **说明**: 进程信息五篇的第五篇。进程文件系统不自己读三家的表，它问系统信息服务要两份现成的数据：整表一份，单个进程一份。本篇讲两份数据怎么填，以及负进程号表示内核任务这条和别处不一样的规矩。

---

## 1 概念

### 1.1 目标读者与前置知识

面向要实现进程文件系统那一端的人。前置知识：16（拿表、查槽）、17（状态怎么定：僵死、停止、能运行那套判断）、02（Minix 扩展编号）。"进程文件系统"是把进程信息做成文件让用户读的那个文件系统，它是这两份数据的消费者。

### 1.2 本章不讲什么

- 状态具体怎么定的——17。
- 第二套格式和进程参数——18、19。
- 拷出——06。
- 进程文件系统怎么把数据摆成文件——文件系统阶段的事，本篇只讲数据怎么来。

### 1.3 两份数据，两种查法

整表快照回答"现在有哪些进程"：扫一遍进程管理的表，在用的、进程号为正的，每行填四个数（标记、进程号、有效用户、有效用户组），僵死的再多加一个僵死标记。空表位跳过，内核伪行跳过（进程号不为正，`:1199-1200`）。估计长度的那次调用直接报整表大小，不拿表（`:1187-1188`）。

单进程快照回答"这个进程怎么样"：调用的人给一个进程号，拿回来十一个字段（端点、标记、在等谁、优先级、用户态时间、内核态时间、三种周期计数、好心值、名字）。名字长度必须是 1（就一个进程号，`:1230-1231`），拿表失败报参数错。

关键的区别在这里：**单进程快照用进程文件系统的规矩，负进程号表示内核任务**（`:1238-1242`，注释把话说全了）。进程号负几，内核任务槽就是几加任务总数，超了报找不到。进程号零也报找不到（查槽函数本来就不收零号，16 §2.3）。这和内核通用查询那套规矩不一样：那边负一表示"全部"。两套规矩并存，调用的人不能混。用哪套，看问的是哪棵树。

标记的优先级和 17 是同一套：僵死排第一，停止第二，能运行第三（`:1267-1272`）。系统服务位独立（特权进程，`:1265-1266`）。名字分两处拿：普通进程抄进程管理的名，内核任务抄内核行的名（`:1280-1285`）。

### 1.4 小结

整表是扫一遍填四个数，单进程是按号取十一个字段。负进程号表示内核任务这条规矩只在这棵树下有效，别和 17、18 的规矩混了。两份数据的内存排布在值表里固定，因为进程文件系统逐字段读。

## 2 C 源码分析

### 2.1 整表（`proc.c:1177-1211`）

估计长度报整表大小（`:1187-1188`）。拿表失败报参数错（`:1190-1191`）。清零。全部扫一遍：不在用或者进程号不为正就跳过（`:1198-1200`）。每行填标记（在用的一直有，僵死加一项，`:1202-1204`）、进程号、有效用户、有效用户组（`:1205-1207`）。整包拷出（`:1210`）。

### 2.2 单进程（`proc.c:1217-1288`）

名字长度必须是 1，否则参数错（`:1230-1231`，注释说目前一次只能查一个，`:1226-1229`）。拿表失败报参数错（`:1235-1236`）。负进程号走内核任务槽（超了报找不到，`:1243-1248`），否则查槽（查不到报找不到，`:1250-1254`）。估计长度报结构大小（`:1256-1257`）。管理标记：进程号为正才用本行，否则零（`:1261`）。清零。端点照填。特权进程加系统服务位（`:1265-1266`）。僵死、停止（被跟踪停住或者内核停住标志）、能运行（内核说能运行）按优先级填（`:1267-1272`，用的 17 同一套判断）。在等谁照填（`:1273`）。优先级、用户态时间、内核态时间、三种周期计数照填（`:1274-1279`）。好心值和名字分两处（`:1280-1285`）。整包拷出（`:1287`）。

### 2.3 两结构和两组标志（`minix/sysctl.h:58-88`）

整表每行四个字段十六字节（`:62-67`）。单进程十一个字段七十二字节（含尾部对齐，`:72-84`）。两组标志各两到四位（`:68-69`、`:85-88`）。头文件原话："不是对外接口的一部分，只给进程文件系统用"。这句话的意思是 NetBSD 的工具不读它们，不是说排布可以随便改。进程文件系统逐字段读，字段顺序和宽度必须和 C 结构一字不差，值表里的排布测试把两处大小固定了（十六和七十二）。

## 3 Rust 设计决策

| # | 决策 | C 做法 | Rust 做法 | 为什么 |
|---|------|--------|-----------|--------|
| D1 | 行取舍变成函数 | 跳过条件散写（`:1199-1200`） | 行要不要函数（`os/servers/mib/src/proc/minix_proc.rs`） | 在用加号为正是两条独立条件，值得独立测 |
| D2 | 进程号解析变成函数 | 分支散写（`:1243-1254`） | 负号判断加槽位换算两个函数（`minix_proc.rs`） | 负号表示内核任务是本篇特有的规矩，和 17、18 不一样，函数名说清这条特有的规矩。进程号零自然落到查不到 |
| D3 | 标记组装变成函数 | 按位或散写（`:1202-1204`、`:1265-1272`） | 整表标记和单进程标记两个函数（`minix_proc.rs`） | 优先级链（僵死压停止压能运行）值得独立测。系统服务位独立 |
| D4 | 名字和标记来源变成函数 | 三元散写（`:1261`、`:1280-1285`） | 来源判断两个函数（`minix_proc.rs`） | 进程号为正才用本行这条线容易看错，函数名写清楚 |
| D5 | 排布进值表 | C 结构 | 对等排布结构加大小测试（`os/libs/minix-types/src/types/sysctl.rs`） | "只给进程文件系统用"不是"可以随便改"。大小测试是排布的最低防线 |

替代方案及否决：负进程号和 17、18 统一成"负一表示全部"——否决。C 注释明确这是进程文件系统的语义（`:1238-1242`），改统一是改语义。周期计数合并成一个——否决，三个计数各有各的来源，调用的人（进程文件系统）都要。

和别的操作系统对照着看：Linux 的进程文件系统自己读内核数据，不经过中间服务。Minix 多了一层：进程文件系统问系统信息服务要，系统信息服务问三家拿。多的这一层把"表怎么拿"（16 的规矩）和"文件怎么摆"（文件系统的事）隔开了。Redox 没有进程文件系统，它的进程方案直接按路径查。本篇保留多一层的设计，因为拿表的规矩（三家的表、失败标记、节流）值得复用，不值得每个消费者写一遍。

## 4 实现详解

### 4.1 模块结构

```
os/servers/mib/src/proc/
├── mod.rs       — 重导出（本篇加了两行）
├── tables.rs    — 16（拿表、查槽，本篇拿来用）
└── minix_proc.rs — 本篇：名字检查、负号判断、槽位换算、行取舍、
                    整表标记、生存状态、单进程标记、名字来源、
                    管理标记来源
```

### 4.2 核心符号表

| 符号 | 来源 | Rust 位置 | 行为 |
|------|------|-----------|------|
| 名字检查 | `:1230-1231` | 名字检查函数 | 长度必须是 1 |
| 负号判断 | `:1238-1242` | 负号函数 | 负号是任务 |
| 槽位换算 | `:1243-1248` | 换算函数 | 超了报找不到 |
| 行取舍 | `:1199-1200` | 取舍函数 | 在用加号为正 |
| 整表标记 | `:1202-1204` | 整表标记函数 | 在用的一直有加僵死 |
| 生存状态 | `:1267-1272` | 状态枚举 | 僵死压停止压能运行 |
| 单进程标记 | `:1265-1272` | 标记函数 | 系统位独立 |
| 名字来源 | `:1280-1285` | 来源函数 | 普通用人名，任务用内核名 |
| 管理标记来源 | `:1261` | 来源函数 | 进程号为正才用本行 |
| 两结构 | `sysctl.h:62-84` | 值表排布结构 | 十六和七十二字节 |

### 4.3 不变量

| 不变量 | 谁保证 | 证据 |
|--------|------|------|
| 进程号零查不到 | 查槽函数本来不收零号 | 16 §2.3 |
| 超范围的负号报找不到 | 换算函数先比任务总数 | `:1244-1245` |
| 僵死排在停止和能运行前面 | 状态枚举的优先级在标记函数里只取一个 | `:1267-1272` |
| 系统服务位不影响生存位 | 两位独立或进去 | `:1265-1272` |
| 排布一字不差 | 大小测试 | 十六和七十二 |

### 4.4 和 C 不一样的地方

§2 有三节，§4 是一个模块：拿表、查槽、拷出按 §1.2 移交出去。状态判断用 17 同一套（本篇不另算）。类别：边界移交出去的，已经声明。
