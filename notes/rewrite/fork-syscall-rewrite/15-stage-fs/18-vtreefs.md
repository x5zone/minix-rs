## 1. 概念：树、钩子与两类查找

### 1.0 章节引言

目标读者是跟完参考实现全部的读者：习惯了磁盘、位图、间接块，现在换一副天地。前置知识只需要一条：有些文件系统的内容不需要持久保存，进程信息关机就没了，读的时候现算就行。

本章建立虚拟树的心智模型。框架拥有三样东西：一棵内存树，记录名字、父子、索引、引用计数；一套钩子，内容生成、目录刷新、状态变更的回调入口；一套分发，把文件系统请求翻译成树操作加钩子调用。服务提供两样东西：启动时搭好的静态树，钩子函数里面按需长出来的动态节点。

### 1.1 为什么需要框架：三个服务长一个样

进程信息、设备管理、伪终端三个服务的需求几乎一样：树形名字空间，内存节点，内容动态生成，挂载卸载语义相同，查找枚举逻辑相同。不抽框架就是三份拷贝，修查找 bug 要修三处。框架把相同的树操作收拢，服务只写不同的内容生成，bug 修一处三处好。

对照 Linux：Linux 的虚拟文件系统层加伪文件系统是同一思想，顺序文件接口让每个伪文件只写内容生成，遍历与缓存由框架管。对照 Redox：Redox 的方案接口让每个方案只实现路径解析与读写，挂载与句柄管理由内核管。两者都是框架管机制、服务填策略，本篇是同一思想在用户态文件服务层的应用。

### 1.2 节点：身份、元数据、树位置、哈希链四组字段

节点分四组字段。身份组：表内序号，调用方看到的号是序号加一，根节点序号零所以号一。元数据组：模式、属主、属组、大小、设备号，与磁盘索引节点的描述部分同构。树位置组：父指针、子链表、引用计数、父内索引、索引槽位数、回调数据、删除标记。哈希链组：名字哈希链、索引哈希链、空闲链。

短名字优化：二十四字节以内的名字存在节点自带的小缓冲里面，超长才堆分配。系统关键路径的名字都很短，短名字走栈上缓冲，分配器压力小。Rust 实现统一用字节向量，不区分 inline 与堆，行为等价，复杂度减半，这是重写对优化的取舍：优化保留语义，实现简化表达。

### 1.3 两套哈希：按名找与按号找

查找有两种：按父目录加名字找，按父目录加索引找。两种各一张哈希表，桶数等于节点总数，名字哈希用 sdbm 多项式，索引哈希用父序号异或索引。双表的原因是两种查找都很频繁：路径解析按名，目录枚举按索引，单表只能加速一种。

sdbm 哈希是公开域算法：初值零，逐字节折入，字节加左移六加左移十六减原值，溢出回绕。多项式系数六万五千五百九十九是经验最优，注释写明换算法风险自负。测试用固定向量锁定多项式，换了算法测试立刻红。

### 1.4 删除两阶段：先摘牌，后拆房

删除分标记与回收两阶段。标记阶段递归标记子节点，从两张哈希表摘除，释放堆名字，置删除标记。非目录立即与父脱钩，目录保留父指针，让已经进入该目录的调用方还能走点点出来。回收阶段等引用计数归零且子链表清空，再与父脱钩并压回空闲链。标记后多次调删除是重试回收，不是重复标记，幂等。

引用计数为零且无子的已标记目录在脱钩时顺带检查父能否回收，链式向上。这是目录树删除的通用处理：删子可能让父满足回收条件，条件满足就地回收，不留垃圾。

### 1.5 引用计数：打开加一，释放减一，批量有玄机

打开按号找节点并加一，释放减一，减到零且已标记且无子就地回收。批量释放是虚拟文件系统服务的调用：参数计数含正在释放的这次引用，所以实现是减计数减一再走一次释放。计数零或超过持有数都报无效参数，这是对调用方的校验，原始实现用断言，Rust 实现用返回值。

### 1.6 查找：点、点点、钩子、哈希四步

单步查找分四步。目录校验：非目录报非目录，超长名报名字过长。点与点点：点停原地，点点去父，根的点点报找不到（根没有父，枚举时点点显示为根自己，查找时越过根顶报错，两处语义不同，文档写明）。其他名字：先调服务的刷新钩子，再查名字哈希表，命中打开并加引用，未命中报找不到。刷新钩子在查找前跑，服务借机把新进程的目录长出来，查得到最新。

### 1.7 枚举：位置计数器走三段

枚举位置计数器走三段：零号是点，一号是点点，二号起是索引槽，索引槽走完是普通子节点。索引槽有空洞就跳过但位置照样消耗，普通子节点跳过已索引的（它们已经有过位置了）。调用方缓冲满就停在当前项，下次从该项继续。位置计数器到顶报输入输出错误，这是对错乱调用方的保护。

调试细节：非索引子节点的断言要求未删除，删除的节点不该出现在子链表里，出现就是框架 bug。Rust 实现用过滤代替断言，逻辑错误报无效而不是崩溃，库不崩进程。

### 1.8 文件读写：钩子填内容，框架管循环

读文件要求普通文件类型，未知号与非文件拒绝。已删除或无读钩子当空文件读，返回零。否则循环调读钩子填暂存缓冲，拷贝给调用方，填不满暂存就停。钩子中途报错且已有输出就报部分字节数，无输出才报错误，部分成功是流式接口的通用语义。

写文件镜像对称：已删除或无写钩子报拒绝访问，零长度直接成功，循环从调用方拷贝进暂存再调写钩子，钩子返回零就停。截断要求普通文件，已删除或无钩子报拒绝访问，非零尾参报无效参数（挖空转全零写的计划还没实现，注释写明待办）。

### 1.9 状态：链接数是布尔，时间是现在

文件状态的链接数是一或零：在树上是一，已删除未释放是零。符号链接报目标长度，调读链接钩子现算，钩子缺席用存的大小。三个时间全填当前时钟，虚拟树不存时间，查一次算一次。改权限与改属主走状态变更钩子，钩子缺席报未实现，成功后重读并报回。卷状态只有两项：不截断标记与名字上限，虚拟树无块，并行度与容量的字段不存在。

### 1.10 挂载：拒绝当根，钩子开场

挂载拒绝根挂载标记，虚拟树不能当根文件系统，根必须是磁盘。根节点加引用，调服务的初始化钩子，报根属性，能力无标志。卸载减根引用，调清理钩子。启动三件套：建树、建额外数据区、建输入输出缓冲，任一失败整个启动失败。信号只响应终止，其他忽略。

### 1.11 本章小结

框架管树、哈希、引用、枚举、循环，服务填内容、刷新、状态变更。节点四组字段，双哈希加速两种查找，删除两阶段保证打开的文件不丢，枚举三段位置保证不重不漏，读写循环保证部分成功，状态查询保证现算现报。下一章进入原始代码验证，逐个文件核对行号和行为。

### 2.11 与 Rust 实现的步骤差异说明

| 差异 | 原始做法 | Rust 做法 | 分类 |
|------|----------|-----------|------|
| 错误传递 | 返回错误码加断言 | 函数返回值加错误枚举 | 设计决策：错误跟随调用返回 |
| 断言守卫 | 九处以上断言 | 参数校验返回错误 | 设计决策：库不崩进程 |
| 全局状态 | 六个静态全局 | 树值拥有全部 | 架构演进：值拥有全部 |
| 函数指针表 | 十三钩子函数指针 | 有默认方法的特征 | 设计决策：缺失行为收拢一处 |
| 名字存储 | 短名小缓冲加堆回退 | 统一字节向量 | 设计决策：语义等价实现简化 |
| 堆分配 | 三块堆内存 | 向量预分配 | 无差异：机制相同 |
| 消息拷贝 | 先拷贝再调钩子 | 调用方供不可变消息 | 设计决策：传输边界上移 |
| 暂存缓冲 | 全局缓冲加大小 | 调用方供暂存长度 | 设计决策：全局消除 |

## 3. Rust 设计决策

> 每个决策先给出依据，再给出替代方案与取舍。对照 Linux 与 Redox 的同类设计。

### 3.1 树做成值：多实例可并行测试（依据：第 1.2 节、第 2.2 节）

节点表、双哈希表、空闲链、腾挪游标、额外区大小收成一个结构体值，测试可建多个并行跑。原始实现用六个静态全局，单进程单树。替代方案是全局静态：测试互斥，多挂载无路。值类型零成本，多实例免费，与第 09 篇内存表值化同一思想。

对照 Linux：Linux 的超级块对象同样一值装全部，挂载即实例化。两者同构。

### 3.2 钩子做成有默认方法的特征（依据：第 1.1 节、第 2.10 节）

十三钩子收成一个特征，每个方法有默认实现，默认复刻框架的无钩子行为：读空、写拒绝、链接组未实现、状态组未实现、查找枚举直通。服务只重写自己有的钩子。替代方案是函数指针结构加空指针判断：每个调用点判空，十三处重复，漏一处就是空指针调用。特征默认把十三个判断收拢到定义处，调用点无分支。

对照 Redox：Redox 的方案特征同样给默认方法，方案只重写自己支持的操作，不支持的报未实现。两者同构。这是架构演进项：函数指针表改特征，三处一致标注（设计快照、本文档、代码注释）。

### 3.3 断言改参数校验（依据：第 2.2 节、第 2.5 节）

新增九断言、查找断言、链接断言全部改返回错误。理由与第 03 篇相同：库不崩进程。调用方传错得到错误码，不是进程终止。测试锁定非法路径：零号查找、根删除、越界索引、超长名字。

### 3.4 腾挪失败报无空间（依据：第 2.2 节）

表满且轮转一圈无可删节点，报无内存。原始实现断言空闲链非空，腾挪失败就崩。进程信息服务的注释写明节点不足降级运行，所以失败必须是可处理的错误，不是崩溃。调用方收到无空间可以降级：跳过本次新建，下次刷新再试。

### 3.5 枚举位置语义忠实复刻（依据：第 1.7 节、第 2.8 节）

点、点点、索引、普通三段，索引空洞耗位置，缓冲满回绕，位置到顶报输入输出错误，逐项对照。理由：枚举是正确性命门，位置错一位调用方死循环或丢项，复刻是最便宜的正确。

### 3.6 决策汇总

| 决策 | 依据 | 替代方案 | 为何不选 |
|------|------|----------|----------|
| 树值 | 第 1.2 节 | 全局静态 | 测试互斥，多挂载无路 |
| 特征默认 | 第 2.10 节 | 函数指针判空 | 十三处重复，漏判崩溃 |
| 断言改错 | 第 2.2 节 | 保留断言 | 库不崩，测试可断言 |
| 腾挪报空间 | 第 2.2 节 | 保留断言 | 服务要降级，需可处理错误 |
| 枚举复刻 | 第 1.7 节 | 简化重写 | 位置错一位丢项或死循环 |

## 4. Rust 实现详解

名字上限六十，短名阈二十四，空索引负一，枚举暂存下限四千零九十六，静态文件与目录模式两常量。错误枚举八变体加错误码映射。钩子错误透传原始码。节点状态五字段。卷状态两字段。目录项三字段。文件状态六字段。钩子特征十三方法全默认。

树结构六字段：节点表、空闲栈、名字桶、索引桶、腾挪游标、额外区大小。新建预分配三向量，根占零号槽，其余压空闲栈。号槽加一，零号拒绝。打开加引用，释放减引用并就地回收，批量释放先减计数减一再走释放。新增九校验，短长名统一向量，头插子链与双桶。删除两阶段：标记递归摘表释名置标记，非目录脱钩，零引用无子回收并链式试父。查找四步：目录、超长、点点、钩子加名表。枚举三段：点、点点、索引、普通，满回绕，顶报错。读写循环：类型校验，删除与缺钩分支，暂存分块，部分成功语义。状态查询：链接布尔，链接现算，时间调用方给。哈希函数锁定多项式。

## 6. 过渡：框架就绪，内容登场
