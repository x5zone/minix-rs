## 一、系统中止子系统

### 1.1 设计理念

**Minix3 的关闭哲学**:

```
传统 Unix 关闭模型:
┌────────────────────────────────────────────────────────────────┐
│  内核直接控制关闭流程                                          │
│  ├── 直接访问硬件                                              │
│  ├── 内核态驱动                                                │
│  └── 同步关闭                                                  │
└────────────────────────────────────────────────────────────────┘

Minix3 微内核关闭模型:
┌────────────────────────────────────────────────────────────────┐
│  协作式关闭流程                                                │
│  ├── 内核协调各系统进程                                        │
│  ├── 用户态驱动参与                                            │
│  └── 通过 Monitor 执行最终关闭                                 │
│                                                                │
│  优势:                                                         │
│  - 更安全: 系统进程可以清理状态                                │
│  - 更灵活: 可以保存系统状态                                    │
│  - 更可靠: 分层处理，避免单点故障                              │
└────────────────────────────────────────────────────────────────┘
```

### 1.2 核心实现

[do_abort.c](file://../minix3/minix/kernel/system/do_abort.c) 实现了系统中止功能:

```c
int do_abort(struct proc * caller, message * m_ptr)
{
/* Handle sys_abort. MINIX is unable to continue. This can originate e.g.
 * in the PM (normal abort) or TTY (after CTRL-ALT-DEL).
 */
  int how = m_ptr->m_lsys_krn_sys_abort.how;

  /* Now prepare to shutdown MINIX. */
  prepare_shutdown(how);
  return(OK);				/* pro-forma (really EDISASTER) */
}
```

#### 1.2.2 prepare_shutdown 逐行分析

**源码位置**: [main.c:351-363](file://../minix3/minix/kernel/main.c#L351-L363)

```c
void prepare_shutdown(const int how)
{
/* This function prepares to shutdown MINIX. */
  static minix_timer_t shutdown_timer;

  /* Continue after 1 second, to give processes a chance to get scheduled to 
   * do shutdown work.  Set a watchog timer to call shutdown(). The timer 
   * argument passes the shutdown status. 
   */
  printf("MINIX will now be shut down ...\n");
  set_kernel_timer(&shutdown_timer, get_monotonic() + system_hz,
      minix_shutdown, how);
}
```

**逐行拆解**:

| 行号 | 代码 | 说明 |
|------|------|------|
| 351 | `void prepare_shutdown(const int how)` | 函数签名：<br>• `how`: 关闭方式（栈上 4 字节）<br>• 无返回值 |
| 354 | `static minix_timer_t shutdown_timer;` | 静态定时器变量：<br>• 存储在 **数据段**（.data 或 .bss）<br>• 生命周期：整个系统运行期间<br>• 必须是 static：定时器需要在函数返回后继续存在 |
| 360 | `printf("MINIX will now be shut down ...\n");` | 输出关闭消息到控制台 |
| 361-362 | `set_kernel_timer(...)` | 设置内核定时器：<br>• 参数1: 定时器结构指针<br>• 参数2: 触发时间 = 当前时间 + 1秒<br>• 参数3: 回调函数 `minix_shutdown`<br>• 参数4: 回调参数 `how` |

#### 1.2.3 minix_shutdown 逐行分析

**源码位置**: [main.c:368-398](file://../minix3/minix/kernel/main.c#L368-L398)

```c
void minix_shutdown(int how)
{
/* This function is called from prepare_shutdown or stop_sequence to bring 
 * down MINIX.
 */

#ifdef CONFIG_SMP
  /* 
   * FIXME
   *
   * we will need to stop timers on all cpus if SMP is enabled and put them in
   * such a state that we can perform the whole boot process once restarted from
   * monitor again
   */
  if (ncpus > 1)
	  smp_shutdown_aps();
#endif
  hw_intr_disable_all();
  stop_local_timer();

  /* Show shutdown message */
  direct_cls();
  if((how & RB_POWERDOWN) == RB_POWERDOWN)
	direct_print("MINIX has halted and will now power off.\n");
  else if(how & RB_HALT)
	direct_print("MINIX has halted. "
		     "It is safe to turn off your computer.\n");
  else
	direct_print("MINIX will now reset.\n");
  arch_shutdown(how);
}
```

### 2.2 核心实现

[do_diagctl.c](file://../minix3/minix/kernel/system/do_diagctl.c) 实现了诊断控制功能:

```c
int do_diagctl(struct proc * caller, message * m_ptr)
{
  vir_bytes len, buf;
  static char mybuf[DIAG_BUFSIZE];
  int s, i, proc_nr;

  switch (m_ptr->m_lsys_krn_sys_diagctl.code) {
    case DIAGCTL_CODE_DIAG:
        buf = m_ptr->m_lsys_krn_sys_diagctl.buf;
        len = m_ptr->m_lsys_krn_sys_diagctl.len;
        if(len < 1 || len > DIAG_BUFSIZE) {
            printf("do_diagctl: diag for %d: len %d out of range\n",
                caller->p_endpoint, len);
            return EINVAL;
        }
        if((s=data_copy_vmcheck(caller, caller->p_endpoint, buf, KERNEL,
                    (vir_bytes) mybuf, len)) != OK) {
            printf("do_diagctl: diag for %d: len %d: copy failed: %d\n",
                caller->p_endpoint, len, s);
            return s;
        }
        for(i = 0; i < len; i++)
            kputc(mybuf[i]);
        kputc(END_OF_KMESS);
        return OK;
        
    case DIAGCTL_CODE_STACKTRACE:
        if(!isokendpt(m_ptr->m_lsys_krn_sys_diagctl.endpt, &proc_nr))
            return EINVAL;
        proc_stacktrace(proc_addr(proc_nr));
        return OK;
        
    case DIAGCTL_CODE_REGISTER:
        if (!(priv(caller)->s_flags & SYS_PROC))
            return EPERM;
        priv(caller)->s_diag_sig = TRUE;
        if (kmess.km_size > 0 && !kinfo.do_serial_debug)
            send_sig(caller->p_endpoint, SIGKMESS);
        return OK;
        
    case DIAGCTL_CODE_UNREGISTER:
        if (!(priv(caller)->s_flags & SYS_PROC))
            return EPERM;
        priv(caller)->s_diag_sig = FALSE;
        return OK;
        
    default:
        printf("do_diagctl: invalid request %d\n", 
            m_ptr->m_lsys_krn_sys_diagctl.code);
        return(EINVAL);
  }
}
```

**源码位置**: [exception.c:333-373](file://../minix3/minix/kernel/arch/i386/exception.c#L333-L373)

```c
void proc_stacktrace(struct proc *whichproc)
{
	u32_t use_bp;

	if(whichproc->p_seg.p_kern_trap_style == KTS_NONE) {
		printf("WARNING: stacktrace of running process\n");
	}

	switch(whichproc->p_seg.p_kern_trap_style) {
		case KTS_SYSENTER:
		case KTS_SYSCALL:
		{
			u32_t sp = whichproc->p_reg.sp;

			/* Full context is not available in the p_reg
			 * struct. Obtain it from the user's stack.
			 * The use stack pointer is always available.
			 * The fact that it's there, and the 16 byte offset,
			 * is a dependency on the trap code in
			 * kernel/arch/i386/usermapped_glo_ipc.S.
			 */

			if(data_copy(whichproc->p_endpoint, sp+16,
			  KERNEL, (vir_bytes) &use_bp,
				sizeof(use_bp)) != OK) {
				printf("stacktrace: aborting, copy failed\n");
				return;
			}

			break;
		}
		default:
			/* Full context is available; use the stored ebp */
			use_bp = whichproc->p_reg.fp;
			break;
	}

#if USE_SYSDEBUG
	proc_stacktrace_execute(whichproc, use_bp, whichproc->p_reg.pc);
#endif /* USE_SYSDEBUG */
}
```

```
│  高地址                                                        │

│  ├──────────────────────────────────────────────────────────┤ │

│  │  返回地址 (return address)                                │ │
│  ├──────────────────────────────────────────────────────────┤ │
│  │  保存的帧指针 (saved EBP) ← 当前 EBP 指向这里             │ │
│  ├──────────────────────────────────────────────────────────┤ │
│  │  局部变量                                                 │ │
│  ├──────────────────────────────────────────────────────────┤ │
│  │  ...                                                      │ │
│  └──────────────────────────────────────────────────────────┘ │
│  低地址                                                        │
└────────────────────────────────────────────────────────────────┘

栈追踪算法:
1. 从当前 EBP 开始
2. 读取 saved EBP (前一个栈帧)
3. 读取 return address (调用点)
4. 输出 return address
5. 移动到前一个栈帧
6. 重复直到 EBP == 0 或达到最大深度
```

### 3.3 更新流程详解

```
┌─────────────────────────────────────────────────────────────────────────┐
│  do_update 完整流程                                                      │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  阶段 1: 参数验证                                                        │
│  ┌───────────────────────────────────────────────────────────────────┐ │
│  │  1. 检查源进程和目标进程端点是否有效                               │ │
│  │  2. 检查两个进程是否都是系统进程                                   │ │
│  │  3. 检查两个进程是否都不可运行                                     │ │
│  │     └── 防止交换运行中的进程                                       │ │
│  │  4. 检查进程是否可更新                                             │ │
│  │     ├── 不能有 RTS_NO_PRIV 标志                                   │ │
│  │     ├── 不能有 RTS_SIG_PENDING 标志                               │ │
│  │     └── 如果在接收，不能同时在发送                                 │ │
│  └───────────────────────────────────────────────────────────────────┘ │
│                                                                         │
│  阶段 2: 特权继承                                                        │
│  ┌───────────────────────────────────────────────────────────────────┐ │
│  │  让目标进程继承源进程的特权:                                       │ │
│  │                                                                   │ │
│  │  1. inherit_priv_irq(): 继承 IRQ 权限                             │ │
│  │     └── 目标进程获得源进程的中断权限                               │ │
│  │                                                                   │ │
│  │  2. inherit_priv_io(): 继承 I/O 权限                              │ │
│  │     └── 目标进程获得源进程的 I/O 端口访问权                        │ │
│  │                                                                   │ │
│  │  3. inherit_priv_mem(): 继承内存权限                              │ │
│  │     └── 目标进程获得源进程的内存访问权                             │ │
│  │                                                                   │ │
│  │  4. 继承 IPC 目标掩码                                             │ │
│  │     └── 目标进程可以与相同的进程通信                               │ │
│  └───────────────────────────────────────────────────────────────────┘ │
│                                                                         │
│  阶段 3: 保存原始状态                                                    │
│  ┌───────────────────────────────────────────────────────────────────┐ │
│  │  保存源进程和目标进程的完整状态:                                   │ │
│  │  ├── orig_src_proc = *src_rp                                      │ │
│  │  ├── orig_src_priv = *(priv(src_rp))                              │ │
│  │  ├── orig_dst_proc = *dst_rp                                      │ │
│  │  └── orig_dst_priv = *(priv(dst_rp))                              │ │
│  │                                                                   │ │
│  │  目的: 支持回滚操作                                               │ │
│  └───────────────────────────────────────────────────────────────────┘ │
│                                                                         │
│  阶段 4: 调整异步消息表                                                  │
│  ┌───────────────────────────────────────────────────────────────────┐ │
│  │  adjust_asyn_table(): 调整异步消息表                              │ │
│  │  ├── 将源进程的异步消息表迁移到目标进程                           │ │
│  │  └── 将目标进程的异步消息表迁移到源进程                           │ │
│  │                                                                   │ │
│  │  为什么需要调整?                                                   │ │
│  │  └── 异步消息表记录了待发送的消息                                 │ │
│  │      └── 交换后，消息应该发送到正确的进程                         │ │
│  └───────────────────────────────────────────────────────────────────┘ │
│                                                                         │
│  阶段 5: 执行交换                                                        │
│  ┌───────────────────────────────────────────────────────────────────┐ │
│  │  1. 交换进程槽内容                                                │ │
│  │     *src_rp = orig_dst_proc                                       │ │
│  │     *dst_rp = orig_src_proc                                       │ │
│  │                                                                   │ │
│  │  2. 交换特权槽内容                                                │ │
│  │     *src_privp = orig_dst_priv                                    │ │
│  │     *dst_privp = orig_src_priv                                    │ │
│  │                                                                   │ │
│  │  3. 调整进程槽指针                                                │ │
│  │     adjust_proc_slot(src_rp, &orig_src_proc)                      │ │
│  │     adjust_proc_slot(dst_rp, &orig_dst_proc)                      │ │
│  │                                                                   │ │
│  │  4. 调整特权槽指针                                                │ │
│  │     adjust_priv_slot(priv(src_rp), &orig_src_priv)                │ │
│  │     adjust_priv_slot(priv(dst_rp), &orig_dst_priv)                │ │
│  │                                                                   │ │
│  │  5. 交换全局进程槽地址                                            │ │
│  │     swap_proc_slot_pointer(ptproc, src_rp, dst_rp)                │ │
│  │                                                                   │ │
│  │  6. 交换 VM 请求条目                                              │ │
│  │     swap_memreq(src_rp, dst_rp)                                   │ │
│  └───────────────────────────────────────────────────────────────────┘ │
│                                                                         │
│  阶段 6: 更新完成                                                        │
│  ┌───────────────────────────────────────────────────────────────────┐ │
│  │  1. 目标进程现在拥有源进程的身份                                  │ │
│  │  2. 源进程现在拥有目标进程的身份                                  │ │
│  │  3. 其他进程看到的是无缝切换                                      │ │
│  │  4. 旧进程可以被终止                                              │ │
│  └───────────────────────────────────────────────────────────────────┘ │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

```c
  flags = m_ptr->SYS_UPD_FLAGS;
```

```c
static void swap_memreq(struct proc *src_rp, struct proc *dst_rp)
{
/* If either the source or the destination process is part of the VM request
 * chain, but not both, then swap the process pointers in the chain.
 */
  struct proc **rpp;

  if (RTS_ISSET(src_rp, RTS_VMREQUEST) == RTS_ISSET(dst_rp, RTS_VMREQUEST))
	return; /* nothing to do */

  for (rpp = &vmrequest; *rpp != NULL;
     rpp = &(*rpp)->p_vmrequest.nextrequestor) {
	if (*rpp == src_rp) {
		dst_rp->p_vmrequest.nextrequestor =
		    src_rp->p_vmrequest.nextrequestor;
		*rpp = dst_rp;
		break;
	} else if (*rpp == dst_rp) {
		src_rp->p_vmrequest.nextrequestor =
		    dst_rp->p_vmrequest.nextrequestor;
		*rpp = src_rp;
		break;
	}
  }
}
```

### 4.1 整体架构设计

```rust
/// 系统控制模块
pub mod control {
    /// 系统中止
    pub mod abort {
        use super::*;
        
        /// 关闭方式
        #[derive(Clone, Copy, Debug, PartialEq, Eq)]
        pub enum ShutdownHow {
            /// 内核崩溃
            Panic,
            /// 停止系统
            Halt,
            /// 重启系统
            Reboot,
            /// 关闭电源
            PowerOff,
            /// 硬件复位
            Reset,
        }
        
        impl ShutdownHow {
            pub fn from_raw(value: i32) -> Result<Self, Error> {
                match value {
                    0 => Ok(Self::Panic),
                    1 => Ok(Self::Halt),
                    2 => Ok(Self::Reboot),
                    3 => Ok(Self::PowerOff),
                    4 => Ok(Self::Reset),
                    _ => Err(Error::InvalidShutdownHow(value)),
                }
            }
        }
        
        /// 关闭管理器
        pub struct ShutdownManager {
            /// 关闭方式
            how: ShutdownHow,
            /// 是否已开始关闭
            in_progress: bool,
        }
        
        impl ShutdownManager {
            /// 执行关闭
            pub fn shutdown(&mut self, how: ShutdownHow) -> Result<!, Error> {
                if self.in_progress {
                    return Err(Error::ShutdownInProgress);
                }
                
                self.in_progress = true;
                self.how = how;
                
                // 1. 通知所有系统进程
                self.notify_processes()?;
                
                // 2. 同步文件系统
                self.sync_filesystems()?;
                
                // 3. 停止设备
                self.stop_devices()?;
                
                // 4. 执行关闭
                self.execute_shutdown()
            }
            
            /// 通知所有系统进程
            fn notify_processes(&self) -> Result<(), Error> {
                for proc in Process::all_system_processes() {
                    proc.send_shutdown_notification()?;
                }
                Ok(())
            }
            
            /// 同步文件系统
            fn sync_filesystems(&self) -> Result<(), Error> {
                Vm::sync_all_filesystems()
            }
            
            /// 停止设备
            fn stop_devices(&self) -> Result<(), Error> {
                for driver in Driver::all() {
                    driver.stop()?;
                }
                Ok(())
            }
            
            /// 执行关闭（永不返回）
            fn execute_shutdown(&self) -> Result<!, Error> {
                match self.how {
                    ShutdownHow::Halt => self.halt_cpu(),
                    ShutdownHow::Reboot => self.reboot_system(),
                    ShutdownHow::PowerOff => self.power_off(),
                    ShutdownHow::Reset => self.reset_hardware(),
                    ShutdownHow::Panic => self.panic_halt(),
                }
            }
            
            /// 关闭 CPU
            fn halt_cpu(&self) -> Result<!, Error> {
                loop {
                    unsafe { asm!("hlt") };
                }
            }
            
            /// 重启系统
            fn reboot_system(&self) -> Result<!, Error> {
                // 使用 ACPI 或键盘控制器重启
                #[cfg(feature = "acpi")]
                acpi::reset();
                
                #[cfg(not(feature = "acpi"))]
                {
                    // 传统方式：键盘控制器
                    unsafe {
                        asm!("outb %al, %dx", in("al") 0xFEu8, in("dx") 0x64u16);
                    }
                }
                
                // 如果重启失败，死循环
                self.halt_cpu()
            }
            
            /// 关闭电源
            fn power_off(&self) -> Result<!, Error> {
                #[cfg(feature = "acpi")]
                acpi::power_off();
                
                // 如果 ACPI 失败，通知 Monitor
                Monitor::power_off();
                
                // 如果 Monitor 也失败，死循环
                self.halt_cpu()
            }
            
            /// 硬件复位
            fn reset_hardware(&self) -> Result<!, Error> {
                // 跳转到复位向量
                unsafe {
                    asm!("jmp *%0" :: "r"(0xFFFFFFF0u32) :: "volatile");
                }
                
                self.halt_cpu()
            }
            
            /// 崩溃停止
            fn panic_halt(&self) -> Result<!, Error> {
                // 显示错误信息
                println!("KERNEL PANIC");
                
                // 停止 CPU
                self.halt_cpu()
            }
        }
    }
    
    /// 诊断控制
    pub mod diagctl {
        use super::*;
        
        /// 诊断请求类型
        #[derive(Clone, Copy, Debug, PartialEq, Eq)]
        pub enum DiagRequest {
            /// 诊断输出
            Diag { buf: VirtAddr, len: usize },
            /// 栈追踪
            StackTrace { endpoint: Endpoint },
            /// 注册消息通知
            Register,
            /// 注销消息通知
            Unregister,
        }
        
        /// 诊断控制器
        pub struct DiagController {
            /// 内核消息缓冲区
            kmess: KernelMessageBuffer,
            /// 注册的进程列表
            registered_procs: Vec<Endpoint>,
        }
        
        impl DiagController {
            /// 处理诊断请求
            pub fn handle(
                &mut self,
                caller: &Process,
                request: DiagRequest,
            ) -> Result<(), DiagError> {
                match request {
                    DiagRequest::Diag { buf, len } => {
                        self.output_diag(caller, buf, len)
                    }
                    DiagRequest::StackTrace { endpoint } => {
                        self.stack_trace(endpoint)
                    }
                    DiagRequest::Register => {
                        self.register(caller)
                    }
                    DiagRequest::Unregister => {
                        self.unregister(caller)
                    }
                }
            }
            
            /// 输出诊断信息
            fn output_diag(
                &mut self,
                caller: &Process,
                buf: VirtAddr,
                len: usize,
            ) -> Result<(), DiagError> {
                // 检查长度
                if len == 0 || len > DIAG_BUFSIZE {
                    return Err(DiagError::InvalidLength(len));
                }
                
                // 从用户空间拷贝数据
                let mut buffer = [0u8; DIAG_BUFSIZE];
                VirtualMemory::copy_from_user(
                    caller,
                    buf,
                    &mut buffer[..len],
                )?;
                
                // 输出到内核日志
                for i in 0..len {
                    self.kmess.putc(buffer[i]);
                }
                self.kmess.putc(END_OF_KMESS);
                
                // 通知注册的进程
                self.notify_registered_procs();
                
                Ok(())
            }
            
            /// 栈追踪
            fn stack_trace(
                &self,
                endpoint: Endpoint,
            ) -> Result<(), DiagError> {
                let process = ProcessTable::get(endpoint)?;
                
                // 输出栈追踪
                println!("Stack trace for process {}:", process.name());
                
                let mut fp = process.frame_pointer();
                let mut pc = process.program_counter();
                
                println!("  PC: {:#x}", pc);
                
                // 遍历调用栈
                for depth in 0..MAX_STACK_DEPTH {
                    // 读取返回地址和上一帧指针
                    let ret_addr = VirtualMemory::read_word(
                        &process,
                        fp + size_of::<usize>(),
                    )?;
                    let prev_fp = VirtualMemory::read_word(
                        &process,
                        fp,
                    )?;
                    
                    if ret_addr == 0 || prev_fp == 0 {
                        break;
                    }
                    
                    println!("  {}: {:#x}", depth, ret_addr);
                    
                    fp = prev_fp;
                }
                
                Ok(())
            }
            
            /// 注册消息通知
            fn register(&mut self, caller: &Process) -> Result<(), DiagError> {
                // 只有系统进程可以注册
                if !caller.is_system_process() {
                    return Err(DiagError::PermissionDenied);
                }
                
                // 设置标志
                caller.privilege().set_diag_sig(true);
                
                // 如果有消息，立即发送通知
                if self.kmess.size() > 0 {
                    Signal::send(caller.endpoint(), Signal::SIGKMESS)?;
                }
                
                Ok(())
            }
            
            /// 注销消息通知
            fn unregister(&mut self, caller: &Process) -> Result<(), DiagError> {
                // 只有系统进程可以注销
                if !caller.is_system_process() {
                    return Err(DiagError::PermissionDenied);
                }
                
                // 清除标志
                caller.privilege().set_diag_sig(false);
                
                Ok(())
            }
            
            /// 通知注册的进程
            fn notify_registered_procs(&self) {
                for endpoint in &self.registered_procs {
                    if let Ok(process) = ProcessTable::get(*endpoint) {
                        if process.privilege().diag_sig() {
                            let _ = Signal::send(*endpoint, Signal::SIGKMESS);
                        }
                    }
                }
            }
        }
        
        const DIAG_BUFSIZE: usize = 4096;
        const MAX_STACK_DEPTH: usize = 20;
        const END_OF_KMESS: u8 = 0;
        
        #[derive(Debug)]
        pub enum DiagError {
            InvalidLength(usize),
            InvalidEndpoint,
            PermissionDenied,
            MemoryAccess(VirtCopyError),
        }
    }

                if !src_proc.is_system_process() || !dst_proc.is_system_process() {
                    return Err(UpdateError::NotSystemProcess);

                    return false;

                if rts.contains(RtsFlags::SIG_PENDING) {
                    return false;
                }

                if rts.contains(RtsFlags::RECEIVING)

                }
```

### 4.2 类型安全的优势

**Rust 重构的核心改进**:

1. **枚举类型确保类型安全**
   - `ShutdownHow` 枚举限制关闭方式
   - `DiagRequest` 枚举区分不同诊断请求
   - 编译时检查所有分支

2. **Result 类型强制错误处理**
   - 所有可能失败的操作都返回 `Result`
   - 必须显式处理错误
   - 避免 C 中忘记检查返回值

3. **所有权系统防止数据竞争**
   - 进程槽交换时，所有权明确
   - 防止并发访问冲突
   - 编译时保证内存安全

4. **模块化设计提高可维护性**
   - 每个子系统独立模块
   - 清晰的接口边界
   - 易于测试和扩展
